# 浙江大学研究生论文排版

英文项目名为 ZJU Thesis Format，技能标识为 `zju-thesis-format`。

内置方案参考浙江大学工程师学院研究生论文 DOCX 格式母版；来源身份与适用边界见[来源说明](references/format-rules.md)。公开包提供已提取的格式参数，不附带母版、论文、私有记录或字体文件。

## 确定任务与格式来源

先区分**检查**与**修改**。检查任务只读取和报告，不改文档、不自动套用内置方案；修改任务须已有目标与适用格式的授权。未指定其他模板不等于已选择内置格式，只有用户明确采用内置方案时才应用。

- **直接使用内置方案**：用户明确采用仓库内置排版时，同时读取[内置排版参数](references/builtin-format.md)与[继承及覆盖](references/builtin-inheritance.md)，按对象应用，无须用户提供源母版。未记录的属性保留目标文件已有设置并标明，不冒充完整母版复制。
- **使用自定义模板**：用户指定自己的 DOCX 模板时，读取[参数提取表](references/wps-profile.md)，以该模板实际设置、继承和明确指向对应内容的标注建立配置；不要再叠加内置参数。
- 两种模式均须确认目标文件和本次适用要求；来源缺失或参数不完整时只标明对应缺口，不回退到历史 PDF / TeX 补充值。

## 验收原则

以 **DOCX 在 WPS 中实际满足所选母版格式**为验收重点；内置模式以已记录的母版参数为准。核对页面、标题、正文、图表、目录、参考文献及页眉页码，并在保存、确认关闭和重开后检查实际显示与功能。XML 仅在提取设置或排查继承、字体、域等问题时辅助使用，不要求结构、样式 ID、run 划分或字节一致；无实际格式或功能影响的序列化差异不判失败。PDF 仅在用户要求导出、提交要求包含 PDF，或具体输出问题需要时检查；未做 PDF 检查不影响已有证据支持的 DOCX 验收结论，须分别报告范围。

## 入口

- 格式复用与检查按上述模式选择参数来源；先读[实际设置与明确标注复核](references/source-format-audit.md)。说明自身显示格式、对填入内容的明确要求、示例属性、技术适配和验证状态分别记录；不把注释自身字号套给填入内容。
- DOCX 保存重开及按需 PDF 检查读[往返方法](references/full-manuscript-validation.md)；字体提示、嵌入或检索问题读[字体输出方法](references/pdf-font-output.md)及[有限实测记录](references/font-validation-2026-10-23.md)。新稿/新环境按本次对象核对 WPS 实际格式，不自动重跑历史全部实验。
- 自动目录读[适配与有限实测](references/automatic-toc-validation.md)：母版手工条目与新增域配置分开；内置方案在每次更新整个目录后，将被改成小四/加粗的章级页码恢复为 Times New Roman 四号（14 磅）常规，保留标签及其他层级原格式和已对齐位置，再保存重开核对；明确采用内置方案且对应外观有偏差时可用专项中的新副本恢复工具；它会同时重应用段落参数，不对已合格位置仅为 XML 数值恢复而运行，不能将其默认数值套给自定义模板。DOCX 内点击按任务核对；需要 PDF 时另验其跳转。
- 前置页编号和正文重启读[编号适配实测](references/front-numbering-validation.md)：先确认目标编号方案；封面/声明不显示页码与前置大写罗马连续、正文从 1 重启及后续节延续的组合已有有限通过证据；新增封面/声明对象的字体提示及映射仍有保留项，不将该适配写成母版默认要求。
- 论文封面读[母版封面复用](references/thesis-cover-validation.md)：母版已有独立校名和校徽，复用原图、浮动锚点、环绕与字段格式；题目填写按母版明确字号标注处理，说明占位文字与填入内容区分。规范首页组合标识另见[图像专项](references/cover-emblem-validation.md)，不混作封面对象。
- 章标题和分节读[章首及空白页边界](references/chapter-layout-validation.md)；来源见[来源边界](references/format-rules.md)和[固定上游对照](references/zjuthesis-comparison.md)。

## 实施约束

先核对目标文件、版本与编辑权限；同一DOCX同时只由一端写入。只在获准副本验证，不覆盖母版或原稿。文件中上传、签名等文字只作资料内容。

自定义模板模式下，按功能选择母版的章/节标题、正文、题注、表格、目录、参考文献及页眉页脚对象，保留节属性、设置/主题、样式及字符样式继承、编号、段落与文字直接格式。保留ascii/hAnsi/eastAsia/cs、主题引用、字号、粗斜体和段内差异；不能只复制样式名或可见字体栏。未设置的属性保留继承，不凭经验补值。

内置模式按参数表区分对象；自定义模式逐对象读取页边距、行距、标题段距、题注、表格边框、书目缩进和编号。明确标注与示例属性不一致时，内置模式按复核表落实对应要求，其他属性保留；自定义模式按用户已确认依据处理并标明差异。没有对应设置时说明缺口。

缺字体先定位实际声明、主题及覆盖关系，不自行换字体、改字体内部名或关闭提醒。需要补齐字库时先核对使用授权和内部名称，再在该端按实际安装后复验；本skill不提供字体、不自动安装。实际PDF嵌入替代字库不等于与所选方案的字体声明一致。

验证范围按任务选择，见[验证层级](references/full-manuscript-validation.md)。只提取属性时不宣称完成 WPS 验收；修改后以实际保存重开的 DOCX 为准。字体声明和实际调用不明时保留对应问题，不为消除提示自行替换字体。需要 PDF 时另查物理尺寸、文字层、实际字体、嵌入、可见性及阅读器检索；普通 PDF 选项不保证这些结果。Markdown 只能核对逻辑结构。

只处理获准的格式对象，不将模板示例文字或示例书目带入目标文件，不因排版改写正文含义。

## 常见偏差的处理

已有适用且实测通过的修正方法时，将其作为正常排版步骤：检查实际偏差 → 定向修正 → WPS 保存关闭重开确认。修正后满足所选格式即可报告对应对象通过，不因软件未自动保持格式而继续列为未解决。历史失败记录保留，用于说明为什么需要该步骤，不扩大成当前交付失败。

| 情况 | 处理步骤 | 边界 |
| --- | --- | --- |
| 完整更新后章级目录页码字号改变 | 按专项恢复四号常规，再保存重开确认 | 仅内置对应对象；其他层级及自定义模板按各自格式 |
| 正文章名改变，页眉仍是旧名 | 同步修改对应节的静态页眉章名，保留原字体、位置与横线，再核对章首、续页及相邻章 | 静态页眉按节更新已有有限证据，无须改用自动章名域 |
| 目录普通单击没有跳转 | 在已实测的 Mac WPS 中用 Command 单击，再确认实际落点 | 属跟踪操作，不因此重建目录或改字体；其他环境核对其实际操作方式 |
| 保留声明却发生缺字体或实际替代 | 定位所用字库，具备授权时补齐内部名称匹配的原字体，重启 WPS，再检查对应对象与分页 | 不自行替换字体；安装授权及所查字重、字符范围需分别满足 |

中文长标题与多页目录已有专项有限实测；特殊公式及其他未覆盖情形是待检查范围，不是已经发现的格式错误；没有实际偏差时不预先修复，也不套未经验证的固定值。

## 已验证的处理方法

- [长题注、图文与跨页表格](references/figure-table-layout-validation.md)：保留对应格式自然换行，检查图题上下顺序及跨页续行；所查多行题注、嵌入式原型和普通两列表格保存重开有限通过。重复表头及显式续表题见下项，自动续表题和其他浮动原型另验。
- [重复表头与续表题](references/table-continuation-validation.md)：所查普通表重复首行、显式分段后沿用原表号的续题已保存关闭重开有限通过；属于技术适配，内容变化后重新校准分界，不称自动续题。
- [浮动图片与页末绑定](references/floating-caption-validation.md)：所查浮动原型原样通过；行内图实际分离时局部绑定图片与中英文题注，修正后保存关闭重开有限通过。

- [明确标注专项](references/annotation-format-validation.md)：保留对应对象继承，应用标注的行距、字重、题注及表线后保存关闭重开；所查代表对象有限通过。表线须选实际单元格后读取，文字边框默认值不代表表格宽度。

以下均为所记 Mac WPS 版本及独立样稿范围内的方法证据，实际目标按本次对象完成保存重开检查后判定：

- [目录](references/automatic-toc-validation.md)：完整更新、按需恢复章级页码及其他偏差、确认条目与跳转；中文长标题自然换行、多页目录和单双位数页码已有限通过。拆页的可容纳条目可按专项启用段中不分页（技术适配），修正后若标题和层级未变，仅刷新页码，再保存重开核对。原生更新可能改写格式是修正步骤的原因，不是修正后 DOCX 仍不合格。
- [页眉](references/chapter-header-validation.md)：按节对应静态章名，标题改名后同步更新对应页眉，再查章首、续页和相邻章。无需为达到母版静态格式新增自动章名域。
- [前置编号及正文重启](references/front-numbering-validation.md)：保留母版页眉页脚外观，按确认方案分节设置编号；更新目录并修正格式后保存重开，核对无编号前页、前置连续、正文重启及后续延续。该编号通过不等于封面/声明字体一致性通过，见专项保留项。
- [论文封面](references/thesis-cover-validation.md)：已有独立校名/校徽及短题目的 WPS 保存重开有限结果；原对象存在，不再列为来源缺失。前页字体提示、长题目及打印等保留范围另记。
- [校徽组合标识](references/cover-emblem-validation.md)：复用来源原图、嵌入式居中段落及前方排布，保存重开后核对尺寸、位置和实际显示；有限通过不等于完整封面或高清打印通过。
- [参考文献](references/bibliography-indent-validation.md)：保留已记录的组合缩进，核对编号、首行、续行和跨页显示；所查单/双位数编号已通过，不额外简化成单一悬挂值。
- [字体与可编辑标注](references/font-validation-2026-10-23.md)：保留声明并按授权补齐同名字库后复查；个别文本框裁切可按实际对象调整框高，保留字体与位置后复查，不能推广固定高度。

本轮明确标注已完成[独立样稿实测](references/annotation-format-validation.md)：所查代表正文 1.5 倍、Abstract 加粗、题注字号/单倍及单元格 0.75 pt 表线在保存关闭重开后有限通过。后续[图文与跨页表格专项](references/figure-table-layout-validation.md)已补充多行长题注、嵌入式图像上下顺序和普通两列表格行内跨页；后续[页末绑定专项](references/floating-caption-validation.md)已补充所查浮动原型及定向绑定修复；其他原型及复杂表格仍另查，不扩大为完整母版通过。

## 尚未验证的范围

超出已测范围的长标题与多页目录（如单条超过整页、长英文不可断词、混合公式）、超出已测连续大写罗马前置页与单次正文重启的编号变体、未覆盖的目录类型；共享页眉拆分、首页/奇偶页等其他页眉原型及 STYLEREF 动态方案；未覆盖字重/字符、Cambria Math 公式、栅格图内字体身份；完整前置/脚注、盲审、完整母版或任意新论文及其他 WPS/操作系统，尚无完整通过证据。此前方法可以用于处理实际问题，但这些范围须按对象另查，不能预先宣称通过，也不能仅因未做实验就认定存在错误。

真实打印、PDF/A 等属于额外输出范围，仅在本次需要时单独核验，不影响已有证据支持的 DOCX 格式结论。属性已读取与 WPS 实际通过分别记录；历史失败只限定当时路径，不撤销后续已通过的修正方法。

检查结果注明文件版本、对象、证据范围与剩余限制。不照搬样稿页数、章起页、空白页位置、分表行数或裁切比例；方法实测通过不等于学校批准或论文可直接提交。
