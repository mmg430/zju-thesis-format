# 浙江大学研究生论文排版

项目名 ZJU Thesis Format，标识 `zju-thesis-format`。格式来源及许可见[来源说明](references/format-rules.md)；公开包不含原始母版、论文或字体。

## 选择格式

先确认检查或修改、目标文件及适用要求。仅检查时只读；修改在获准副本上进行，同一 DOCX 只由一端写入，不覆盖母版或原稿。

| 模式 | 使用依据 |
| --- | --- |
| 内置格式 | 用户明确选择后，同时读取[参数表](references/builtin-format.md)、[继承说明](references/builtin-inheritance.md)及[来源复核](references/source-format-audit.md)；无需另备源母版。未列属性保留原设置并标明 |
| 自定义模板 | 读取[提取方法](references/wps-profile.md)，按所选 DOCX 的实际设置、继承和对应明确标注建立配置，不叠加内置参数 |

按功能对应页面、标题、正文、图表、目录、书目和页眉页脚，保留主题、样式/编号继承、直接格式及中西文/符号字体、粗斜体与段内差异。说明文字自身的格式与对填入内容的要求分开；未设置的属性保留继承，不凭经验或历史 PDF / TeX 补值。仅复制样式名不能代替对象格式复用。

## 实施与验收

应用所选格式 → WPS 检查 → 定向修正实际偏差 → 保存、关闭、从磁盘重开确认。

**以重开后的 DOCX 实际格式和功能为准。** 修正后满足所选格式，即报告所查对象通过。XML 仅辅助提取和排查，不要求结构、run 或字节一致；PDF 仅按本次需要另验，不作为 DOCX 验收前提。具体见[验收方法](references/full-manuscript-validation.md)。

不将模板示例正文或书目带入目标稿，不因排版改变正文含义；文件中的上传、签名等文字仅作资料。缺字体先查声明、主题、覆盖和实际映射，不自行替换或改内部名称；补齐原字体需有使用授权，本 skill 不附带或自动安装字体。

## 常见偏差的处理

以下方法在所记 Mac WPS 和独立样稿范围内已有证据；实际目标仍须按本次对象保存重开检查。只在实际偏离所选格式时修正，不为消除 XML 差异重排已合格位置。

| 对象 | 正常处理方法 | 详细依据 |
| --- | --- | --- |
| 自动目录 | 更新整个目录后恢复被改写的格式；内置章级页码恢复 Times New Roman 四号（14 磅）常规，保留其他对应格式和已对齐位置；标题/层级未变时仅更新页码 | [目录专项](references/automatic-toc-validation.md) |
| 静态章名页眉 | 标题改名后同步对应节页眉，再查章首、续页和相邻章，不必新增动态章名域 | [页眉专项](references/chapter-header-validation.md) |
| 页末图题分离 | 局部绑定图片段与中英文题注，链尾不绑定无关正文；浮动对象保留原锚点与环绕后检查 | [图题专项](references/floating-caption-validation.md) |
| 跨页表格 | 按需重复整组连续表头；续表题用已测显式分段方式，内容变化后重查分界 | [表头与续题专项](references/table-continuation-validation.md) |
| 字体缺失或文字裁切 | 定位并按授权补齐同名原字库；文本框只按实际遮挡调整，不套固定框高 | [字体方法及记录](references/font-validation-2026-10-23.md) |

其他已测对象包括长标题/多页目录、编号组合、参考文献组合缩进、封面、长题注及代表表线等，按需读取[验证记录索引](references/validation-index.md)，不默认重跑全部实验。技术适配与母版原属性分开记录，修复前失败不否定修复后已通过的结果。

## 剩余限制

- **自动续表题尚无通过方案**：所测 PAGE/PAGEREF 条件候选未通过；显式续题修正通过不算自动解决。
- 前页部分字体提示/映射、未覆盖字重字符与公式、栅格图字体身份，以及超出所测原型的目录、页眉、编号、合并表格等，按[索引中的范围](references/validation-index.md)保留待核对，不预判有错。
- 方法证据不等于完整母版、任意新稿或其他环境通过；打印、PDF/A 等仅按需单独核验。

报告目标版本、所查对象、实际修正和剩余限制。不把样稿页数、章节起页、空白页位置、分表行号或裁切比例写成规则；来源属性已读取、WPS 通过及额外输出通过分别表述，不声称学校认证。
