# 明确格式标注的 WPS 保存重开实测

## 范围与结果

在 Mac WPS 教育版 12.1.25867 中，以独立中性文字样稿复用母版对应段落、样式继承及表格结构，落实[复核表](source-format-audit.md)中的明确标注。完成实际另存 DOCX、通过菜单关闭并确认回到首页、从保存文件重新打开；随后逐对象定位文字，查看字体/段落/单元格边框面板及页面显示。最后关闭样稿。本轮没有导出 PDF，也没有修改母版或论文。

| 所查对象 | 重开后 WPS 实际观察 | 结论 |
| --- | --- | --- |
| 致谢、中文摘要、附录代表正文段落 | 对应段落面板均为 1.5 倍，保留原缩进和网格设置；页面中正文显示正常，未见裁切；致谢字体面板为仿宋、小四、常规，西文 Times New Roman | 所查正文行距有限通过 |
| Abstract 标题 | 字体面板显示西文 Times New Roman、小三、加粗；标题居中且可见。保留原东亚声明，不因此改为别的中文字体 | 所查标题加粗有限通过 |
| 英文摘要正文对照 | 段落面板仍为固定值 24 磅 | 保留英文原行距通过，不把中文 1.5 倍扩大到英文 |
| 图题、表题 | 两类题注的段落面板均为单倍；字体面板为仿宋 / Times New Roman、五号、常规；表题原首行缩进及与网格不对齐设置保留 | 所查题注字号及行距有限通过 |
| 表线 | 选中有边线的实际单元格后，“边框和底纹”显示单元格、自定义、0.75 磅；页面可见对应横线；保存文件中对应表级/单元格线宽辅助回读保持 | 所查边线宽度有限通过，不声称所有表型均已验证 |

保存文件的辅助属性回查与界面观察相符；不以 XML 一致代替实际检查。源母版哈希未变。公开仅保留方法和范围，样稿、截图、界面读数、源文档及字体不分发。

## 可复用步骤

1. 在副本中选用对应对象，实施标注明确的字号、字重、行距和线宽；其他缩进、段距、网格、字体脚本及继承保留，不全篇归一。
2. 实际保存、确认关闭，再重开保存文件；按内容定位各对象，查看相应面板并检查页面显示。有偏差时定向恢复，再完成保存重开。
3. 核对表线前先选中真实单元格或表格对象，再打开边框面板。选中文字时显示的“文字 / 无 / 0.5 磅”是文字边框上下文，不能据此认定表格被改成 0.5 磅；仅在对话框切换“应用于”也不等于已经读取原单元格的线宽。选择实际单元格后再读取，本轮得到 0.75 磅。
4. 页面中的编辑虚框与实际边线分开，不为消除虚框擅自新增或删除表线；表级与单元格覆盖分别核对。

## 保留范围

本轮未发现上述所查设置在保存重开后失效，但只验证代表对象。没有逐一验证全部正文变体、全部图题缩进、长题注、图题与真实图片的相对位置、任意复杂合并/续表或完整母版；也没有新做实际字库身份、全部字符、公式、跨平台、打印或 PDF 输出测试。三线表的具体结构仍按用途和原对象确认，0.75 磅通过不授权把所有特殊表统一去线。样稿页数、页码、文本长度与表格行列数不作为通用规则。
