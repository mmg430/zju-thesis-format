# 自动目录：格式适配与有限 WPS 实测

2026-10-23，Mac WPS 教育版 12.1.25867（25867），独立中性样稿。保留参考母版的页面、标题和正文格式；未覆盖母版或论文。原母版、样稿、截图、PDF 和私有日志不公开，以下为维护者实测摘要，使用者须核验自己的输出。

## 母版属性与新增适配

参考母版的所查目录为手工条目，没有 TOC 域或可直接复用的 TOC 层级样式链。可见手工引导符与已设置的点引导制表位是两个层次，不能据此声称原文档已有自动目录。

| 对象 | 从母版实际属性取得 | 自动目录中的处理 |
| --- | --- | --- |
| 目录标题 | 仿宋 / Times New Roman，15 磅加粗、居中，无章标题段距 | 保留原对象设置，不纳入目录正文条目 |
| 章级条目 | 标签文字继承 12 磅并加粗；手工引导符及页码文字为 14 磅常规；line=360 auto | 按标签、制表引导及页码域分别保留混合格式，不整行统一字号或粗体 |
| 一级节条目 | 12 磅常规；firstLineChars=100 与 firstLine=240 twip；line=360 auto | 保留组合字段，不擅改为左缩进或悬挂 |
| 二级节条目 | 12 磅常规；firstLineChars=200 与 firstLine=480 twip；line=360 auto | 同上；此次只测试单行条目，长标题续行未验证 |
| 条目制表位 | right、pos=6141 twip、leader=dot | 自动制表引导代替手工引导符，属于适配，不承诺逐字形复刻手工省略号 |
| 正文章 / 一级节标题 | 已有 outlineLvl=0 / 1，连同直接字体等设置保留 | 用于目录前两级，不重套通用标题外观 |
| 正文二级节标题 | 使用 Normal，无显式大纲级别，12 磅常规等实际设置保留 | 只对选定的此类标题添加 outlineLvl=2；不能将所有 Normal 段落提升为第三级 |

样稿新增 `TOC \o "1-3" \h \z \u` 域和由对应手工条目派生的三级目录样式。域、样式映射、大纲补充、链接和书签都是本次技术适配，不是母版原有设置。自定义模板须重新提取自己的目录属性，不能叠加此处数值。

## 可复用步骤

1. 按所选格式建立标题层级映射；外观与大纲语义分别处理。目录标题不作为目录条目，普通正文不提升大纲级别。
2. 建立自动目录域与对应层级样式；由 WPS 实际生成结果。标题、层级或条目发生变化时选择“更新整个目录”，不能只更新页码。
3. 保存后回读实际结果。若 WPS 改写了母版格式，在独立副本按目录角色重新应用源段落、字体及混合格式，保留 TOC / HYPERLINK / PAGEREF 指令、嵌套结构及书签，不把目录拆成纯文本。
4. 对混合字号的页码域同时处理域载体和结果文字；不能仅检查可见结果 run。直接设置是适配中维持原有效外观的方法，不冒充母版每个 run 都有这些显式属性。
5. WPS 另存、确认关闭并从磁盘重开，再导出 PDF。核对目录条目与正文、缓存页码与实际页、内部链接目标和实点落点；DOCX 与 PDF 交互分别报告。在本次 Mac WPS 中，按住 Command 单击目录标签文字或右侧页码可跟踪；跳转后选中落点标题核实，不能只看页码或把点击后域变灰当作成功。其他环境先验证实际跟踪操作。
6. 再次更新整个目录后，重复格式回读、必要恢复和输出验收。此次没有证明“恢复一次后永久不再改写”。

## DOCX 点击后续复验

在保持上轮格式和字段结构的独立副本上重新测试，没有转换超链接结构、更换样式或字体，也没有改变 WPS 全局跟踪设置。普通点击/双击有停留目录或选中域的情况；采用 Command 单击后，章、一级节、二级节的标签文字与右侧页码均能跳转。在另存、确认关闭、磁盘重开后完成这六项，使用行首及选至行尾的选择确认实际落点标题，有限通过。不是只确认目标物理页或 PDF 正常。

保存前后正文 XML 除 `_GoBack` 导航书签位置外相同，样式、主题及字体表保持，settings 仅增加会话 rsid；这些会话变化不作为排版修复。新 PDF 与上轮对应输出的五页渲染在 1600 像素页面高度时一致；全部目录链接目标和三级 PDF 书签回查正确，PDF 三级实点及中文检索再次通过。

本轮消除了“该样稿 DOCX 精确跳转尚无通过证据”的缺口，**没有隔离上轮操作不稳定的唯一原因**。不将此前异常直接归因为文档损坏、键位错误或缓存，也不声称普通单击、所有 WPS 设置或其他版本均相同。交互手点仅覆盖每级各一条的标签与页码，其余链接有静态引用与 PDF 目标核查证据。

## 未覆盖范围

多页目录、长标题换行、罗马数字前置页、混合页码及重启、无编号前后置标题、图表目录、目录与分页反复变化后的稳定性、完整母版或论文、其他 WPS 版本和操作系统仍未验证。DOCX 普通点击、其他跟踪设置及环境的交互方式仍须单独确认。

不把样稿条目数、总页数或目标页号写成通用规则；不要据本次结果称自动目录已经完整复原母版或完成全稿验收。
