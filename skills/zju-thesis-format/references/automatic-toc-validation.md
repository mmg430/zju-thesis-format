# 自动目录：格式适配与有限 WPS 实测

本页保留既有实验的实际范围。日常验收以 WPS 中 DOCX 实际格式与功能为主；XML 仅辅助排查，PDF 按需另查，见[验收方法](full-manuscript-validation.md)。

2026-10-23，Mac WPS 教育版 12.1.25867（25867），独立中性样稿。保留参考母版的页面、标题和正文格式；未覆盖母版或论文。原母版、样稿、截图、PDF 和私有日志不公开，以下为维护者实测摘要，使用者须核验自己的输出。

## 母版属性与新增适配

参考母版的所查目录为手工条目，没有 TOC 域或可直接复用的 TOC 层级样式链。可见手工引导符与已设置的点引导制表位是两个层次，不能据此声称原文档已有自动目录。

| 对象 | 从母版实际属性取得 | 自动目录中的处理 |
| --- | --- | --- |
| 目录标题 | 仿宋 / Times New Roman，15 磅加粗、居中，无章标题段距 | 保留原对象设置，不纳入目录正文条目 |
| 章级条目 | 标签文字继承 12 磅并加粗；手工引导符及页码文字为 14 磅常规；line=360 auto | 按标签、制表引导及页码域分别保留混合格式，不整行统一字号或粗体 |
| 一级节条目 | 12 磅常规；firstLineChars=100 与 firstLine=240 twip；line=360 auto | 保留组合字段，不擅改为左缩进或悬挂 |
| 二级节条目 | 12 磅常规；firstLineChars=200 与 firstLine=480 twip；line=360 auto | 同上；此次只测试单行条目，长标题续行未验证 |
| 条目制表位 | right、pos=6141 twip、leader=dot | 自动制表引导代替手工引导符，属于适配，不承诺逐字形复刻手工省略号 |
| 正文章 / 一级节标题 | 已有 outlineLvl=0 / 1，连同直接字体等设置保留 | 用于目录前两级，不重套通用标题外观 |
| 正文二级节标题 | 使用 Normal，无显式大纲级别，12 磅常规等实际设置保留 | 只对选定的此类标题添加 outlineLvl=2；不能将所有 Normal 段落提升为第三级 |

样稿新增 `TOC \o "1-3" \h \z \u` 域和由对应手工条目派生的三级目录样式。域、样式映射、大纲补充、链接和书签都是本次技术适配，不是母版原有设置。自定义模板须重新提取自己的目录属性，不能叠加此处数值。

## 实际结果

| 检查项 | 观察及状态 |
| --- | --- |
| 标题收集 | 初始三级九条；更名、新增三级标题并插入测试页后，更新整个目录得到十条，层级及名称正确。有限通过 |
| 只更新页码 | 原有条目页码改变，但旧章名及条目数保留；不能用于标题更名或结构变化后的完整更新 |
| 更新整个目录的格式保留 | **未通过**。WPS 将所查右制表位改为 8300 twip，并改变部分字符设置（历史属性观察；制表位数值变化本身不等于实际格式失败，见后续 DOCX 专项）；后续基线与 `MERGEFORMAT` 对照仍改写制表位，不能标成一键保留母版格式 |
| 更新后重新应用母版格式 | 保留全部域指令与书签，在独立副本恢复条目各角色格式后，完成 WPS 另存、确认关闭、磁盘重开和 PDF 导出。所查制表位、组合缩进及混合页码字体有限通过 |
| 仅设置页码结果 run | **未通过**。XML 结果文字虽设为 14 磅常规，导出章级页码仍为 12 磅粗体 |
| 页码域整体格式 | 对 PAGEREF 的 begin、instrText、separate、结果及 end 所在 run 一并设置对应页码格式后，导出章级页码调用常规 TNR，名义 14 磅；PDF 绘制约 14.05 磅，其余两级为 12 磅。后者是渲染观察，不将源参数改成 14.05 |
| 保存重开 | 修复后、另存前的导出与 WPS 保存重开后导出的五页，在页面高度 1600 像素时逐页渲染完全一致；仅限这次往返，不证明后续再次更新目录仍保留格式 |
| PDF 页码与跳转 | 十条缓存页码与实际目标页、页脚 PAGE 对应；十个条目链接和十个页码链接的目标正确，PDF 书签三级层次正确；三个层级分别实点到达相应标题。有限通过 |
| DOCX 内点击跳转 | 首轮未稳定确认；后续在同版 Mac WPS 的独立副本中，完成另存、确认关闭与磁盘重开，Command 单击三级条目的标签及右侧页码，六项落点均为对应标题。**仅该操作与抽样范围有限通过**；普通点击不作通过承诺，见下节 |
| PDF 尺寸、文字和字体资源 | 各页 595 × 842 磅，有文字层；阅读器指定中文词得到目录及正文两处命中。所用字体资源含非空嵌入流及 ToUnicode；这不是全部字形身份认证 |

## 可复用步骤

1. 按所选格式建立标题层级映射；外观与大纲语义分别处理。目录标题不作为目录条目，普通正文不提升大纲级别。
2. 建立自动目录域与对应层级样式；由 WPS 实际生成结果。标题、层级或条目发生变化时选择“更新整个目录”，不能只更新页码。
3. 保存后先在 WPS 中对照母版检查目录实际外观与功能；需要定位原因时才回读 XML。若 WPS 改写了母版格式，在独立副本按目录角色重新应用源段落、字体及混合格式，保留 TOC / HYPERLINK / PAGEREF 指令、嵌套结构及书签，不把目录拆成纯文本。
4. 若混合字号页码在 WPS 中显示不符，且需用底层设置修复，应同时处理域载体和结果文字，不能只改结果 run。显示及功能已符合要求时不额外改写域结构。直接设置是适配中维持原有效外观的方法，不冒充母版每个 run 都有这些显式属性。
5. WPS 另存、确认关闭并从磁盘重开，先检查 DOCX 实际格式与功能；需要 PDF 时再导出检查。核对目录条目与正文、缓存页码与实际页、内部链接目标和实点落点；DOCX 与 PDF 交互分别报告。在本次 Mac WPS 中，按住 Command 单击目录标签文字或右侧页码可跟踪；跳转后选中落点标题核实，不能只看页码或把点击后域变灰当作成功。其他环境先验证实际跟踪操作。
6. 再次更新整个目录后，重新检查 DOCX 实际格式与功能；有偏差再恢复，PDF 按需另查。后续两轮已验证可重复恢复；没有证明“恢复一次后永久不再改写”。

## 可重复恢复工具

后续独立样稿先完整更新，再恢复格式，完成 WPS 另存、确认关闭、磁盘重开及 PDF 导出；第二轮另有更名、新增条目和分页变化。两轮都恢复了制表位、组合缩进及混合页码字号。第一轮输出与此前同输入的已验证五页渲染一致；第二轮核对新增内容、页码和全部链接目标，新增条目的 DOCX / PDF 实点及中文检索通过。**通过的是更新后恢复流程，原生更新保留格式仍未通过**。

明确采用内置方案后，可在关闭待处理文档的情况下运行，路径仅为示例：

```sh
python3 scripts/restore_toc_format.py /path/to/updated.docx /path/to/restored-new.docx
```

以上命令从安装后的 skill 目录执行。[脚本](../scripts/restore_toc_format.py)只用 Python 标准库，按[内置纯格式配置](../scripts/builtin_toc_profile.json)恢复，不依赖源母版文件。配置从已核对的对应属性与有效外观派生，显式字符覆盖属于自动目录技术适配；它不是完整母版或全校统一规范。

- 只支持单个复杂 TOC 域、可识别的 `TOC 1–3` / `目录 1–3` 样式及 PAGEREF 结构。按目标样式名映射，不固定样式 ID、条目数、目录文字或页码。
- 只写新副本，拒绝同路径及已有输出；保留域指令、书签、编号、命名空间声明和非目录对象；不支持的前缀或前缀重绑定明确拒绝。页码域从 begin 到 end 的载体与结果一起恢复。
- 脚本不更新目录内容、不控制 WPS、不保证渲染。处理前先由 WPS 完成“更新整个目录”并保存关闭；处理后必须重开新副本、另存关闭重开，在 WPS 中检查实际目录格式及功能；PDF 按需导出另验，不能只凭脚本成功判通过。
- 自定义模板不能直接使用默认内置配置。`--profile` 可读取自行提取的同结构纯格式 JSON（`schema=1`，按级别提供 `paragraph` pPr、`label` / `page` rPr XML，不含源样式 ID）；自定义配置及其他复杂目录结构尚未做 WPS 实测，不自动回退到内置数值。

此次四项合成检查验证输入及非目标保持、完整域载体恢复、覆盖拒绝和异常结构拒绝；与真实 WPS 两轮证据分开记录。最终保留命名空间声明的工具输出又完成一次 WPS 保存关闭重开及导出，六页与该轮前一恢复结果渲染一致。脚本并未使后续完整更新自动保留格式，下一次更新仍需重新处理。

## DOCX 点击后续复验

在保持上轮格式和字段结构的独立副本上重新测试，没有转换超链接结构、更换样式或字体，也没有改变 WPS 全局跟踪设置。普通点击/双击有停留目录或选中域的情况；采用 Command 单击后，章、一级节、二级节的标签文字与右侧页码均能跳转。在另存、确认关闭、磁盘重开后完成这六项，使用行首及选至行尾的选择确认实际落点标题，有限通过。不是只确认目标物理页或 PDF 正常。

保存前后正文 XML 除 `_GoBack` 导航书签位置外相同，样式、主题及字体表保持，settings 仅增加会话 rsid；这些会话变化不作为排版修复。新 PDF 与上轮对应输出的五页渲染在 1600 像素页面高度时一致；全部目录链接目标和三级 PDF 书签回查正确，PDF 三级实点及中文检索再次通过。

本轮消除了“该样稿 DOCX 精确跳转尚无通过证据”的缺口，**没有隔离上轮操作不稳定的唯一原因**。不将此前异常直接归因为文档损坏、键位错误或缓存，也不声称普通单击、所有 WPS 设置或其他版本均相同。交互手点仅覆盖每级各一条的标签与页码，其余链接有静态引用与 PDF 目标核查证据。

## DOCX 实际格式专项复验（不导出 PDF）

同版 Mac WPS 的独立单页、三层目录样稿再次执行“更新整个目录”，实际另存、确认关闭、磁盘重开。对照母版副本的 WPS 画面及字体栏：母版章级页码为 Times New Roman 四号常规，原生更新后变为小四；因此原生完整保持格式仍未通过。

本轮保留已与母版画面对齐的段落定位，仅恢复标签、引导及页码的对应字符格式，再完成 WPS 另存、关闭及重开。所查章级页码恢复四号常规；三级缩进、点引导、页码对齐及无缺字/裁切的实际显示有限通过，抽查的第三级条目可到达相应标题。本轮未导出 PDF、未做 XML 一致性比较，不新增 PDF 通过结论。

**不能仅因制表位数值改变而判实际格式失败。** 母版使用手工引导符，已设置的制表位并不直接等于这些字符的可见末端。本轮原生更新的页码列与母版画面右端接近，未机械改回源制表位。先在 WPS 中对照实际外观，再决定是否需要恢复段落位置或仅恢复字符格式；内置恢复工具默认会重应用已记录段落参数，不能在外观已合格时无差别运行。此次保留当前段落定位的配置仅有该样稿有限证据，不作为新的通用数值或完整自定义模板验证。

单页短标题、所查混合字号及一次更新后的恢复是本轮范围；多页、长标题及其他环境仍须按实际对象核对。原先 PDF 与属性对照结果保留为历史实验，不能代替此次 DOCX 实际检查。

## 未覆盖范围

多页目录、长标题换行、罗马数字前置页、混合页码及重启、无编号前后置标题、图表目录、超出上述两轮的目录与分页反复变化稳定性、完整母版或论文、其他 WPS 版本和操作系统仍未验证。DOCX 普通点击、其他跟踪设置及环境的交互方式仍须单独确认。

不把样稿条目数、总页数或目标页号写成通用规则；不要据本次结果称自动目录已经完整复原母版或完成全稿验收。
