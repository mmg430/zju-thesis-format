# 参考文献组合缩进实测 — 2026-10-23

本页保留既有实验的实际范围。日常验收以 WPS 中 DOCX 实际格式与功能为主；XML 仅辅助排查，PDF 按需另查，见[验收方法](full-manuscript-validation.md)。

本记录验证[内置方案](builtin-format.md)中参考文献的组合缩进，不为其他模板指定通用悬挂值。测试环境为 Mac WPS 教育版 **12.1.25867（25867）**；使用独立中性样稿，不修改参考母版或原稿。原始母版、样稿、截图及本地日志不随仓库发布，以下为维护者的有限实验摘要。

## 本次实验的输入与操作

从参考 DOCX 原样复用参考文献段落属性及所选文字 run 属性，保留原样式、编号、默认值、主题及字体声明。用 12 条中性测试文字覆盖单/双位数编号、中文长段、中英文混排和自动跨页续行；测试文字不是真实题录。页尺寸及边距保留，样稿不测试原页眉页码。

| 层次 | 保留的关键属性 |
| --- | --- |
| List Paragraph1 段落样式 | basedOn Normal；line=360 auto；firstLineChars=200、firstLine=420 twip；仿宋 / Times New Roman |
| 编号级 ilvl=0 | decimal、start=1、lvlText=`[%1]`、左对齐；left=420、hanging=420 twip；编号字形 Times New Roman |
| 段落直接设置 | firstLineChars=0、jc=left、widowControl 开启；保留原 numPr 关联和 run 的复杂文种字号等局部属性 |

本次实验当时的操作顺序为：打开输入样稿并导出基线 PDF → WPS 另存新 DOCX → 确认样稿标签关闭 → 从磁盘重新打开已保存副本 → 普通 PDF 导出 → 回读属性、检查全部输出页并比较。

没有删除或归一化任何缩进字段，没有手工改成单一悬挂值，也没有替换字体。文件名与样式 ID 均不作为格式恒等的判据。

## 观察与结果

| 检查 | 实际结果与证据范围 |
| --- | --- |
| 保存与重开 | 新 DOCX 实际写入且文件哈希与输入不同，测试文字保持一致；样稿标签关闭后重新从磁盘打开。重开及导出均成功 |
| 属性保留 | 12 条段落的 pPr、所用列表样式的 pPr/rPr、编号级子属性经回读比较保持一致；样式 ID 被重编号，按样式名称和引用重映射核对；编号级新增 tentative=0；Normal 将原 docDefaults 中继承的字体主题、kern 和语言写成显式属性，经对照与原默认值一致。未将这些变化称为 XML 逐字不变 |
| 编号起点 | `[1]` 至 `[12]` 的编号均在正文左边界起排 |
| 首行文字与续行 | PDF 绘制指令测得，两者均在正文左边界右侧 **21 磅（420 twip）** 起排；单/双位数编号、所查中英文续行及跨页续行均一致。测量使用实际 Tm 位置并结合逐页视觉检查，不只依赖文本抽取器回调坐标 |
| 往返稳定性 | 保存前与保存重开后，两次 WPS PDF 的分页、文字位置及逐页渲染一致；以相同工具渲染至页面高度 1800 像素，全部页像素相同；视觉未见编号重叠、缺字或裁切 |
| 输出辅助检查 | 两次输出物理页面均为 595 × 842 磅，存在文字层；全部测试段落抽取可对应；PDF 字体资源为 FangSong 与 TimesNewRomanPSMT 子集，嵌入流及 ToUnicode 存在。此项不等于新增完整字形身份核验 |
| 阅读器检索 | WPS PDF 对测试短语的精确查找返回 12 处，与测试条目数相符；属于真实阅读器操作，非仅脚本文本提取 |

**通过结论：在本次环境和样稿范围内，保持这组三层原设置可以稳定完成 WPS 保存、关闭重开及 PDF 导出；无须修正缩进属性。** 21 磅是这组设置的实际输出结果，不是从某一个字段推定的通用优先级，也不授权将组合设置改写为扁平参数。

## 复用与仍未验证项

复用时同时保留段落样式、编号定义和直接格式，重映射样式及编号 ID，并在 WPS 中用目标内容核对编号、首行与续行对齐及跨页显示；无须重复本实验的 XML 比较或 PDF 像素对照。不能只设 hanging=420、删除 firstLineChars，或把测得的绝对页面坐标写成通用规则；本记录不规定页数、条目所在页或分页位置。

本次没有测试三位数及更长编号、其他编号级/重启策略、其他字重或缺字回退、其他 WPS/操作系统，也不证明所有书目类型、完整母版或整篇论文通过。未改变真实题录，不涉及题录准确性认证。自动目录、动态跨章页眉及其他未覆盖对象继续保留原验证状态。
