# 内置排版方案

本方案提取自浙江大学工程师学院研究生论文 DOCX 格式母版的实际设置及明确指向待填内容的格式标注。可以直接采用，无须另行提供该母版文件；它是一套已记录的格式配置，不是全校统一规范或完整母版的逐属性复制。

应用时须同时读取[继承及覆盖](builtin-inheritance.md)，区分默认值、样式、编号与文字直接格式。以下单位和对象区别应保留。[实际属性与明确标注复核](source-format-audit.md)记录差异、采用方式和验证状态；本次落实的行距、加粗、题注和表线已有[独立样稿有限实测](annotation-format-validation.md)，仅覆盖专项所查对象。数值及标注已经回查源文件；参考文献组合缩进已完成[有限 WPS 实测](bibliography-indent-validation.md)，[跨章静态页眉](chapter-header-validation.md)也完成有限实测，[自动目录适配](automatic-toc-validation.md)已有单页及中文长标题多页 DOCX 实测，历史 PDF 检查另记范围，指定 Mac WPS 的 Command 点击已有三级抽样证据，其他操作/环境须重验；其他未覆盖继承信息仍以 XML 回查为限。各专项通过范围及剩余限制统一见[验证记录索引](validation-index.md)。

## 字体与颜色

逐对象字体、字号和颜色见[核对表](font-size-color-audit.md)。常用字体行不是全篇覆盖规则：部分节标题保留宋体，声明标题保留方正小标宋简体，符号及图内可编辑文字按原 run；未单列颜色、显式黑色、主题超链接色与说明深灰色分别处理。属性核对后，姓名字段及宋体节标题已完成 WPS 保存关闭重开的有限检查，主题链接蓝色有重开显示证据；日期、其他前页字段及精确链接色等边界见核对表末节，不扩大到完整前页。

## 封面与前后置页

[前页格式表](front-matter-format.md)记录论文封面含校名/校徽、中文题名页、声明及授权、致谢与作者简历预留的版式、字体、字号和颜色。按该表区分显式黑色、未单列颜色及图片对象；作者简历不补造正文参数。完整字体映射及新增页面外观仍以专项所记范围为限。

| 表格边框 | 按明确标注通常采用三线表、表线 0.75 磅（sz=6）；示例实际 sz=4（0.5 磅）的差异见复核表。须检查单元格覆盖及特殊表结构，不全表强制去内部线；所查单元格 0.75 磅已有限通过 |
| 参考文献标题 | 15 磅、加粗章标题格式 |

章标题在所查直接格式及对应样式中没有单列的行距属性，不自行补成固定倍数或两行占位。题注虽未直接列行距，但有明确单倍标注，按该标注执行。适用时保留现有样式继承；无对应样式或完整属性时记录缺口，不能声称已经复原整个源母版。局部强调、特殊符号和中西文混排按对象处理，不将表中的常用字体覆盖所有字符。

图内文字、流程图、曲线轴标、照片文本框、公式正斜体及参考文献题录的明确说明，按[逐项复核表](source-format-audit.md#图表公式和参考文献)检查；它们不因已录入参数而自动成为 WPS 已验证结果。

## 编号、页眉页脚与输出

目录、图表编号、参考文献编号以及页眉中的章名，根据目标文档内容建立或更新，不携带任何样例文字、固定页码、章起页或空白页位置。页码使用 PAGE 域；源文件各节未明确页码格式或起始值，手工目录中的罗马数字不等于节编号规则。[前置编号与正文重启实测](front-numbering-validation.md)是按确认方案增加的技术适配，不是本表默认参数；分节、继承、编号起点和页眉结构需结合目标文档确认，不默认增加奇数页起章或空白页。

参考母版页眉章名是静态文字，按节引用对应部件；[实测](chapter-header-validation.md)支持保留格式的静态对应及定向更新，不能只改正文标题后期待自动同步。页眉空白及对齐原样保留，长章名等未覆盖变化须重验。

内置方案没有穷举封面、所有公式、全部特殊字形和其他未列对象。未记录项保留目标文件的已有设置并标明，不从其他模板补齐。需要严格保留某份模板的全部属性时，改用[自定义模板模式](wps-profile.md)。

字体须由使用者按合法授权准备，不随 skill 分发。采用这些参数后，以目标 DOCX 在 WPS 中保存、关闭重开后的实际格式为准，核对分页、页眉页码及对应对象。XML 仅辅助排查；PDF 按导出或提交需要另查，不作为日常 DOCX 验收前提，见[验收方法](full-manuscript-validation.md)。

手工目录的引导符可见宽度不由已设制表位数值单独决定；自动目录先对照 WPS 实际位置，不能只为恢复 XML 数值而移动已对齐的页码列。内置恢复工具会同时应用段落参数，使用前须确认实际需要，见[DOCX 专项](automatic-toc-validation.md)。

内置自动目录的日常步骤：更新整个目录 → 检查并将偏离的章级页码恢复为 Times New Roman 四号（14 磅）常规 → 保存关闭重开确认。章级标签及节级页码不随之统一改号；已对齐位置保留，见[具体步骤](automatic-toc-validation.md)。

中文长标题与多页自动目录已有[专项有限实测](automatic-toc-validation.md)：沿用对应字号、行距及首行缩进自然换行，末行页码右对齐；条目拆页时可按对象启用段中不分页，属于技术适配，不改本表母版参数。修正后若标题和层级未变，仅刷新页码并保存重开核对。

无编号封面/声明与前置编号、正文重启的组合已有[有限 WPS 实测](front-numbering-validation.md)：空页脚按节隔离，编号前置首节明确恢复 PAGE 页脚和确认的起点。该方案是编号适配，不新增母版默认编号参数；完整封面/声明字体仍有提示及映射未确认项。

## 可选来源图像对象

来源规范说明首页的校徽组合 PNG（551 × 147 像素）约 9.299 × 2.481 cm，嵌入式、所在段落居中，前方段落排布保留；已有[有限 WPS 实测](cover-emblem-validation.md)。它不在后面的学位论文封面示例页中，不默认添加到论文封面；公开包不附带原图，采用时须另有适用依据和对应原图。该图约 150 PPI，不称高清矢量或打印已验证。

## 论文封面原型

母版论文封面另有独立校名字样（约 6.033 × 1.926 cm）和圆形校徽（约 2.275 × 2.154 cm），两者为浮动锚点、上下型环绕；不能套用上节首页组合图的嵌入式参数。题目填写按母版明确标注：中文仿宋小二号（18 磅）加粗，英文 Times New Roman 16 磅加粗；这与说明文字本身的显示字号分开。其他字段按对应实际格式保留。原图、位置、参数来源及有限 WPS 结果见[封面专项](thesis-cover-validation.md)，公开包不附带原图或封面文件。

长题注、嵌入式图像上下顺序及普通两列表格原样跨页已有[专项有限实测](figure-table-layout-validation.md)。长题注保留对应字体/字号、单倍和原缩进自然换行；表格保留行跨页设置，核对页间续行、行序与末行。所查浮动原型及页末图题绑定见[后续实测](floating-caption-validation.md)：仅在实际分离时局部绑定，保留母版外观。后续[重复表头与显式续表题](table-continuation-validation.md)及所查多行/横纵合并表头已有限通过，属按需技术适配；自动续表题当前尚无通过方案：所测条件域候选未通过，其他自动方案及复杂表格待验证。
