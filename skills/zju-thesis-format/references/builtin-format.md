# 内置排版方案

本方案提取自浙江大学工程师学院研究生论文 DOCX 格式母版的实际属性。可以直接采用，无须另行提供该母版文件；它是一套已记录的格式配置，不是全校统一规范或完整母版的逐属性复制。

应用时须同时读取[继承及覆盖](builtin-inheritance.md)，区分默认值、样式、编号与文字直接格式。以下单位和对象区别应保留。数值已经回查源文件属性；参考文献组合缩进已完成[有限 WPS 实测](bibliography-indent-validation.md)，[跨章静态页眉](chapter-header-validation.md)也完成有限实测，[自动目录适配](automatic-toc-validation.md)已有单页及中文长标题多页 DOCX 实测，历史 PDF 检查另记范围，指定 Mac WPS 的 Command 点击已有三级抽样证据，其他操作/环境须重验；其他未覆盖继承信息仍以 XML 回查为限。已有有限实测及未覆盖范围见[验证记录](font-validation-2026-10-23.md)。

## 页面

| 项目 | 内置设置 |
| --- | --- |
| 纸张 | 11900 × 16840 twip，约 209.903 × 297.039 mm |
| 上、下边距 | 各 1440 twip，即 2.54 cm |
| 左、右边距 | 各 1800 twip，即 3.175 cm |
| 页眉距边 | 851 twip，约 1.501 cm |
| 页脚距边 | 992 twip，约 1.750 cm |
| 装订线 | 0 |
| 文档网格 | lines，linePitch=312 twip；段落自身的网格设置分别保留 |
| 镜像页边距、奇偶页不同 | 不额外启用 |

1 磅 = 20 twip。不要用名义 A4 的整数尺寸覆盖上述源值。

| 参考文献条目 | 仿宋 12 磅 / Times New Roman，1.5 倍行距、左对齐；编号级 left/hanging 均 420 twip，与样式及直接首行设置并存；保持组合的 WPS 往返已在单/双位数编号样稿中通过，实测首行文字与续行均距正文左边界 21 磅；不简化原属性组合 |

章标题和题注在所查直接格式及对应样式中没有单列的行距属性，不自行补成固定倍数。适用时保留现有样式继承；无对应样式或完整属性时记录缺口，不能声称已经复原整个源母版。局部强调、特殊符号和中西文混排按对象处理，不将表中的常用字体覆盖所有字符。

## 编号、页眉页脚与输出

目录、图表编号、参考文献编号以及页眉中的章名，根据目标文档内容建立或更新，不携带任何样例文字、固定页码、章起页或空白页位置。页码使用 PAGE 域；源文件各节未明确页码格式或起始值，手工目录中的罗马数字不等于节编号规则。[前置编号与正文重启实测](front-numbering-validation.md)是按确认方案增加的技术适配，不是本表默认参数；分节、继承、编号起点和页眉结构需结合目标文档确认，不默认增加奇数页起章或空白页。

参考母版页眉章名是静态文字，按节引用对应部件；[实测](chapter-header-validation.md)支持保留格式的静态对应及定向更新，不能只改正文标题后期待自动同步。页眉空白及对齐原样保留，长章名等未覆盖变化须重验。

内置方案没有穷举封面、所有公式、全部特殊字形和其他未列对象。未记录项保留目标文件的已有设置并标明，不从其他模板补齐。需要严格保留某份模板的全部属性时，改用[自定义模板模式](wps-profile.md)。

字体须由使用者按合法授权准备，不随 skill 分发。采用这些参数后，以目标 DOCX 在 WPS 中保存、关闭重开后的实际格式为准，核对分页、页眉页码及对应对象。XML 仅辅助排查；PDF 按导出或提交需要另查，不作为日常 DOCX 验收前提，见[验收方法](full-manuscript-validation.md)。

手工目录的引导符可见宽度不由已设制表位数值单独决定；自动目录先对照 WPS 实际位置，不能只为恢复 XML 数值而移动已对齐的页码列。内置恢复工具会同时应用段落参数，使用前须确认实际需要，见[DOCX 专项](automatic-toc-validation.md)。

内置自动目录的日常步骤：更新整个目录 → 检查并将偏离的章级页码恢复为 Times New Roman 四号（14 磅）常规 → 保存关闭重开确认。章级标签及节级页码不随之统一改号；已对齐位置保留，见[具体步骤](automatic-toc-validation.md)。

中文长标题与多页自动目录已有[专项有限实测](automatic-toc-validation.md)：沿用对应字号、行距及首行缩进自然换行，末行页码右对齐；条目拆页时可按对象启用段中不分页，属于技术适配，不改本表母版参数。修正后若标题和层级未变，仅刷新页码并保存重开核对。

无编号封面/声明与前置编号、正文重启的组合已有[有限 WPS 实测](front-numbering-validation.md)：空页脚按节隔离，编号前置首节明确恢复 PAGE 页脚和确认的起点。该方案是编号适配，不新增母版默认编号参数；完整封面/声明字体仍有提示及映射未确认项。
