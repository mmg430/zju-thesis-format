# 跨章静态页眉映射实测 — 2026-10-23

本页保留既有实验的实际范围。日常验收以 WPS 中 DOCX 实际格式与功能为主；XML 仅辅助排查，PDF 按需另查，见[验收方法](full-manuscript-validation.md)。


**通过：按节对应的静态章名，以及改名后定向更新对应页眉部件。母版不具备只改正文标题就自动更新页眉的机制；STYLEREF 自动域方案仍未验证。** 本记录不把这两类能力混为一项。

环境为 Mac WPS 教育版 **12.1.25867（25867）**。只使用中性独立样稿，母版和原稿未被覆盖；原始 DOCX、PDF、截图及本地日志不公开，以下为维护者的有限实验摘要。

## 母版实际结构与测试设计

已读取的母版页眉为静态文字，各节通过 `headerReference` 及关系目标引用页眉部件；未发现页眉中的 STYLEREF 或其他取章名域。本次复用正文章页对应的一种页眉原型：两段结构、首段空段、后段直接两端对齐，保留原有空白、run 属性、样式链、9 磅字号及 0.75 磅底边线。原有字号、字体主题和中西文差异均未统一改写。

建立三章样稿，各有章首和续页，用测试分页符覆盖同章续页；保留母版页尺寸、边距、网格及节起始设置，不开启首页不同、奇偶页不同或奇数页起章。各章分别引用独立页眉部件；首节显式接入母版中从前置节继承的 PAGE 页脚，后续节保留页脚继承。页数和章名长度属于测试条件，不是排版参数。

测试包括三个案例：

1. **基线对应**：三个等长中性章名分别出现在正文标题和对应节页眉。WPS 导出基线，再另存新 DOCX、确认标签关闭、从磁盘重开并再次导出。
2. **只改标题对照**：仅修改第二章正文标题的中性章名，保留其静态页眉，实际导出观察是否自动更新。
3. **定向更新**：从目标节的 headerReference 经关系表找到对应部件，只更新该部件章名，不改其格式、空白或其他节；另存新 DOCX、确认关闭、从磁盘重开并导出。

两次改名均为等长替换，保持各 run 的文字范围和属性。没有按“第几个 header 文件就是第几章”猜测映射，没有将原有空格改成制表位，也没有增加自动取章名域。

## 观察与结论

| 检查 | 实际结果及边界 |
| --- | --- |
| 静态跨章对应 | 三章的首、续页均显示各自章名，未串到其他章；保存前与保存重开后的全部页面在相同工具、页面高度 1400 像素下逐页渲染完全一致 |
| 只改正文标题 | 正文出现新章名，对应页眉仍显示旧章名。**自动跟随正文改名不成立**；不是字体替换或缓存修复问题，也不能把该对照报告为自动映射通过 |
| 定向更新页眉 | 更新后目标章首、续页显示新章名；与只改标题的对照相比，像素差异仅出现在目标章的页眉文字区域，其他章节全部页面不变 |
| 格式及引用回读 | 三个独立 default 页眉引用及目标文字保留；页眉段落属性和逐字符解析后的字符属性一致；页尺寸、边距、列间距及网格的原有数值保留，页眉字号和边线属性保持 |
| WPS 写回变化 | 样式 ID 重编号，按名称及引用核对；WPS 另显式写入 cols:num=1、docGrid:charSpace=0。原字段保留且输出对照一致，不声称 XML 逐字不变 |
| 页码与输出 | 所查 PAGE 域在章间连续，位置保持；PDF 物理尺寸均为 595 × 842 磅，存在文字层；页眉位置及底边线未见漂移、裁切或重叠。未测试编号重启策略 |
| 字体与检索辅助证据 | PDF 字体资源有非空嵌入流和 ToUnicode；页眉实测使用 SimSun 中文与 Calibri 数字，保留母版声明及主题，未自行替换。WPS PDF 精确检索新章名返回三处，分别为两页页眉及一处正文标题；不等于新增完整字形身份核验 |

## 可复用处理

先按目标文档的实际节边界、headerReference、关系表和继承关系建立“章—节—页眉部件”的对应，再按该范围更新静态章名。章标题改变后同步检查对应页眉；不能指望静态文字自动读取正文。完成保存、关闭重开后，在 WPS 中核对目标章首、续页与相邻章；需要 PDF 时另查对应输出。

母版中的空白参与页眉定位，本次仅通过等长短章名。长章名、不同字符宽度、换行或重新排布均须另测，不把缩小字号、删空格或改对齐作为已验证的通用修复。

若多个节共享同一个页眉部件，直接修改可能影响所有引用者；先确认获准修改范围。本次未测试共享部件的拆分、显式取消“同前节”、首页/奇偶页页眉、连续分节、章间空白页、长章名、其他 WPS/操作系统、整份母版或论文，以及 STYLEREF 等自动方案。这些项继续标为未验证，不推广样稿的章起页、页数、节序、部件名或页码起点。
