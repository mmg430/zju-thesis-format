# 章标题、章间空白页与页眉页码

内置模式按[内置方案](builtin-format.md)设置章标题；自定义模式按母版对应段落及样式的实际设置复用，保留字号、行距、段前段后间距、对齐和分页属性。节起始及页眉页脚继承分别核对；不从其他模板额外开启双面、奇数页分节、奇偶页脚或显式空白页。

静态章名替换是项目内容适配；共享header需要按目标稿实际结构判断，静态页眉样稿不证明自动域或跨章映射通过。章间空白页按实际PDF逐页核对有无页眉页码，任何手动补页都在内容改变后重判，不套固定位置。

旧版分节/显式补页方案是旧条件下的技术探索，已退出默认配置。需要采用时先明确该项目要求并在新副本验证，不能将历史案例当作学校明文规范。
