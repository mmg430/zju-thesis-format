# 章标题、章间空白页与页眉页码

内置模式按[内置方案](builtin-format.md)设置章标题；自定义模式按母版对应段落及样式的实际设置复用，保留字号、行距、段前段后间距、对齐和分页属性。节起始及页眉页脚继承分别核对；不从其他模板额外开启双面、奇数页分节、奇偶页脚或显式空白页。

参考母版采用分节引用的静态章名，没有自动取章名域。[跨章专项实测](chapter-header-validation.md)已在指定 WPS 的三章首/续页样稿中验证静态对应和定向更新；仅改正文标题不会同步静态页眉，STYLEREF 自动方案仍未验证。静态章名替换是目标内容适配；共享 header 需要按实际引用及修改范围判断，不能把某个部件名直接当作章号。章间空白页先在 WPS 中核对有无页眉页码；需要 PDF 时再查实际输出，任何手动补页都在内容改变后重判，不套固定位置。

旧版分节/显式补页方案是旧条件下的技术探索，已退出默认配置。需要采用时先明确该项目要求并在新副本验证，不能将历史案例当作学校明文规范。
