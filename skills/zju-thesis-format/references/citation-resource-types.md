## 图书与专著

依据8.2及表1（页8—9），版次依据7.4（页5）。

- 必备：题名、文献类型标识；电子资源还需载体标识及获取/访问路径。
- 有则必备：主要责任者、其他题名信息、版本、出版地、出版者、出版年、引文页码。其他责任者可选；电子资源的永久标识符可选。
- 第一版可不著录；其他版本说明应著录，不能把所有版次删去。译者等其他责任者置于类型标识后、版本前；不能把译者当成原作者。
- 出版信息顺序为出版地、出版者、出版年；实际引用部分按真实引文页码处理，不强填整书起止页或总页数。书中一章等析出文献另按8.3及表2（页9—10），区分章节责任者/题名与整书责任者/题名，并用析出关系连接。

仅表示字段次序的纸本结构：

```text
[序号] 主要责任者. 题名: 其他题名信息[M]. 其他责任者. 版本. 出版地: 出版者, 出版年: 引文页码.
```

不是要求填满全部槽位：按上述必备性取舍，省略项目时一并整理相邻分隔符。电子图书采用实际载体（如 `[M/OL]`），按表1补路径及适用标识符；不能仅因网上取得就改成网页类型。

## 学位论文

依据8.7及表6（页14—15），学位相关出版信息按7.5.1（页6）。

- 必备：题名、文献类型标识、学位授予单位；电子资源还需载体标识及获取/访问路径。
- 有则必备：主要责任者、其他题名信息、授予单位所在地、学位授予年、引文页码；电子资源的永久标识符可选。
- 按实际学位授予信息填写单位及年份，不拿数据库、保存单位、上传日期或下载日期直接替代。标准本类格式不单列强制“硕士/博士”槽位，不擅自在题名后追加固定学位描述。
- 授予单位未知时应记录缺项并回源查证，不能因模板中有“保存单位”就认定已满足必备项。

纸本字段次序：

```text
[序号] 主要责任者. 题名: 其他题名信息[D]. 学位授予单位所在地: 学位授予单位, 学位授予年: 引文页码.
```

在线版本按实际资源采用 `[D/OL]` 并记录路径、适用的永久标识符；不自动套入网站/网页的日期槽位。

## 会议文献

先按8.6.1（页13）判断出版形态，不把全部会议文献强配一个通式。

| 形态 | 处理方式 |
| --- | --- |
| 已出版的整部会议录 | 按8.2图书项目和格式；会议录类型为 `[C]`，在线版按实际载体处理 |
| 已出版会议录中的一篇论文 | 按8.3析出规则，区分论文与会议录，用 `//` 连接；8.6.1有 `[C]//` 示例，不能使用母版旧 `[A]` 含义 |
| 以连续出版物或其中析出文献形式出版 | 按8.4或8.5相应项目及格式，不因曾在会议报告就一律改成图书会议录 |
| 上述之外的会议文献 | 按8.6.2表5及8.6.3（页14），记录会议名称、会议年份等适用字段 |

出版会议录中的论文，纸本字段次序可表示为：

```text
[序号] 论文责任者. 论文题名[C]//会议录责任者. 会议录题名. 出版地: 出版者, 出版年: 析出页码.
```

这里省略了可出现的其他题名、版本及其他责任者槽位，完整字段仍按8.3；出版年与会议举行年不混用。

8.6.3形态的必备项为题名、类型标识，电子资源还需载体及路径；主要责任者、其他题名信息、会议名称、会议年份、引文页码为有则必备，永久标识符为电子资源可选。其字段次序为：

```text
[序号] 主要责任者. 题名: 其他题名信息[C]//会议名称, 会议年份: 引文页码.
```

在线时使用实际载体并补路径。不能把表5未列的出版者、会议举办地或精确会期无依据地强加为此形态的必填字段；题名原有相关信息按原资源保留。

## 网络资源：先辨类型，再查网站或网页规则

8.11.1（页18）明确：以网页形式提供的图书、期刊、会议录、学位论文等仍按相应类型处理；其他网站、网页及其内容才按8.11。结合7.3、附录A使用实际类型/载体，不能一律改成 `[EB/OL]`。数据集、预印本等另有专条，本页不以网页规则替代。

| 项目 | 网站：8.11.2表10（页18—19） | 网页：8.11.3表11（页19） |
| --- | --- | --- |
| 题名、类型、载体、引用日期、获取/访问路径 | 必备 | 必备 |
| 主要责任者、其他题名信息、创建或修改日期 | 有则必备 | 有则必备 |
| 永久标识符 | 表10未单列，不新增强制槽位 | 可选 |

网站与网页分别记录所引对象的题名，不能把每一网页都只记网站首页；责任者确无署名时不凭域名猜作者。日期依7.6（页7）用 `YYYY-MM-DD`：创建/修改日期用圆括号、引用日期用方括号；没有可靠创建/修改日期时不编造，引用日期记录实际访问所引资源的日期，不回填假日期。

通用网站/网页的字段次序可表示为：

```text
[序号] 主要责任者. 题名: 其他题名信息[EB/OL]. (创建或修改日期)[引用日期]. 获取和访问路径.
```

网页如适用可再按7.9记录永久标识符；具体对象属于其他类型时，上述 `[EB/OL]` 不适用。仅是链接到某资源的页面，不证明已经取得或阅读该资源。

## 缺失信息与母版旧说明

- 出版地未知：7.5.2.3（页6）允许纸本中文用 `[出版地不详]`、外文用 `[S.l.]`，无出版地的电子资源可省此项。出版者未知按7.5.3.3（页6—7）分别允许 `[出版者不详]`、`[s.n.]`，电子资源无出版者可省。均是条款允许的处理，不伪造真实出版信息，也不把“有则必备”变成任意省略。
- 出版年无法确定时，7.5.4.3（页7）允许依次选版权年、印刷年、估计出版年，估计值加方括号；本配置不提供无证据自动估年的方法。具体值无依据时仍待查。
- 母版“专著版次第一版可略”与7.4相容；“专著起止页码”应按实际引文页码理解，不能强填整书范围。母版学位论文的“保存地点、保存单位、年份”改按授予信息处理；会议及笼统电子文献示例改按上述分型、路径及日期要求。题录差异不覆盖母版字体、行距、缩进。
