# 文献著录与正文标引

## 标准选择与来源

用户明确选择 **GB/T 7714—2025** 时，按该版处理著录及标引；本配置提供顺序编码制的接入方法，不覆盖其他任务明确选定的标准。

[国家标准官方信息](https://openstd.samr.gov.cn/bzgk/std/newGbInfo?hcno=C6CE52E55AC09B9C79A20AEA77CEDD14)确认《信息与文献 参考文献著录规则》GB/T 7714—2025 于 2025-12-02 发布、2026-07-01 实施。官方信息页因版权不提供全文。

2026-10-24 取得[高校学报网站托管的正式版扫描件](https://www2.abc.edu.cn/xbbjb/upload/2026-01/26012010262341.pdf)，核对封面标准号、发布及实施日期与官方元数据一致；逐页阅读本页所列条款。全文来源为高校网站，不声称来自官方全文服务；本页公开规则摘要和条款定位，不转载扫描件。条款页码均指标准印刷页码。

## 题录规则与母版外观分开

字体、字号、颜色、行距及组合缩进仍按所选 DOCX 格式。以下处理明确采用本标准时的著录；不因题录修正而重排书目外观。

| 对象 | 已核对规则 | 正式文本定位 |
| --- | --- | --- |
| 作者姓名 | 姓前名后；西文姓全拼，名可用不带缩写点的首字母，不能一律要求全名或全部姓氏大写。拼音姓名与西文姓名分别按条款处理 | 7.1.1，页4 |
| 作者人数 | 同类责任者不超过3人全部著录；超过3人可列前3人后加“等”或对应词，不把“可”改为所有条目必须截断 | 7.1.2，页4 |
| 期刊字段 | 有卷号：`刊名, 年, 卷(期): 页码`；无卷号：`刊名, 年(期): 页码`。不为缺失卷号补0，不把平台占位值直接当真实卷号 | 8.5.1.1例1—3，页11；8.5.3，页12—13 |
| 页码 | 用实际题录的页码或适用的文章编号；引文参考文献与阅读型参考文献的页码用途按原条款区分，不猜缺页 | 7.7，页7；8.5.1.1，页11 |
| DOI | 独立的 `DOI:标识符` 写法有正式示例支持；获取路径已含持久标识符时可不重复。不能要求所有条目都补DOI，也不因有DOI自动改为 `[J/OL]` | 7.9，页8；8.5.2—8.5.3，页12—13 |
| 标点 | 按字段使用句点、逗号、冒号、括号等；刊名与年份之间用逗号，无卷号时年份直接接期号。条款未据此证明所有字符宽度或空格必须统一为某种形式 | 6.1—6.2，页3；8.5.3，页12—13 |
| 正文及排序 | 普通正文顺序编码按首次出现排序，同一文献重复引用复用首次编号；多篇与连续编号按条款处理，文末按序号排列。自动编号脚注的特例另按对应条款，不直接套用普通正文规则 | 9.2.1—9.2.2，页23—25 |
| 类型代码 | `[A]` 为档案；`[EB]` 为网站/网页。会议析出文献按会议条款选择类型及析出关系，不能统一写成 `[A]` | 附录A表A.1，页28；8.6 |

正文上标沿用本配置母版的明确标注，属于所选版式；不凭一条文末示例推定交叉引用功能。资源类型、载体和字段按实际采用的文献版本选择，不能把所有文献套成期刊或网络资源。

## 母版说明的差异处理

| 母版旧说明 | 采用2025标准时的处理 |
| --- | --- |
| 英文名字不可缩写、后续作者另用姓名次序及连接词 | 改按7.1.1—7.1.2；不据母版旧说明猜全名或改作者顺序 |
| 中文“多个作者”取前三位加“等” | 明确不超过3人全部列出；超过3人可按条款截取 |
| 期刊示例中刊名后句点、年份与无卷号期号间逗号 | 按期刊字段结构修正，见上表 |
| `[A]` 指会议析出文章、`[EB]` 指电子公告 | 更新为2025附录A代码含义；具体文献另选适用类型 |
| 中文全角标点、英文半角标点 | 保留为母版原说明，不冒称2025强制条款。任务明确选择的统一标点外观可记录为适配，不据此改变字段分隔关系 |
