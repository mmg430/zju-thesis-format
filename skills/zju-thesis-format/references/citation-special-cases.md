# 其他文献类型与特殊情况

适用于明确采用GB/T 7714—2025的任务，通用规则、正式扫描件来源回[引用规则](citation-rules.md)，图书、学位、会议、网页回[常用分类](citation-resource-types.md)。本页2026-10-24按正式文本核对，页码指印刷页；条款核对不等于WPS或自动导出通过。题录规则不覆盖所选母版的字体、字号、颜色、行距和组合缩进。

## 报告、标准、专利、报纸

| 类型与依据 | 著录处理 |
| --- | --- |
| 报告，8.8、表7，页15—16 | 图书、图书析出、连续出版物或其中析出形态的报告按8.2—8.5相应规则。其他报告按8.8.3：责任者、题名及其他题名信息、报告编号、类型/载体、发布日期、引文页码、路径及永久标识符。表7中题名和类型必备，责任者、其他题名、编号、发布日期及引文页码有则必备；电子资源载体与路径必备，永久标识符可选。不把母版“报告会主办单位”强作所有报告的出版者 |
| 标准，8.9、表8，页16—17 | 标准编号、名称必备；结构为标准编号后接名称、类型/载体，再接适用路径和永久标识符。不沿用母版将编号与名称颠倒或强加出版地/出版社的旧通式。类型标识一般必备；表8注仅规定标准化文件中类型标识可选，不能扩为任意论文都省略。电子载体/路径必备，永久标识符可选 |
| 专利，8.10、表9，页17—18 | 申请者/所有者、题名、专利申请号及类型标识必备；其他题名、公告/公开日期、引文页码有则必备；电子载体/路径必备，永久标识符可选。顺序为申请者/所有者、题名及相关题名、编号、类型/载体、公告/公开日期与引文页码、路径及标识符。保留真实编号及所引版本，不能把发明人、申请人、申请日、公开日混为一项；不另造固定“国别：编号”槽位 |
| 报纸中的文章，8.5.1.1及8.5.3，页11—13；7.5.4.2，页7 | 用 `[N]` 或适用电子载体；记录文章责任者、题名、报纸名、出版日期及版次/位置等真实字段。日期采用YYYY-MM-DD，版次置圆括号；不是期刊卷期。表4的条件项目及电子路径按8.5.2处理，不把缺失版次编成页码 |

报告的普通结构导航：`责任者. 题名: 其他题名信息: 报告编号[R]. 发布日期: 引文页码. 路径. 永久标识符.`；专利导航：`申请者/所有者. 题名: 其他题名信息: 申请号[P]. 公告或公开日期: 引文页码. 路径. 永久标识符.`。这些不是全槽位必填模板；缺项与分隔符按真实项目处理，电子资源补适用载体。

## 档案与地图

- **档案**：8.12及表12（页20），图书或书中析出形式先按8.2/8.3；其他档案记录责任者、题名及其他题名、档号、类型/载体、收藏者所在地、收藏者、形成日期、引文页码、路径、标识符。题名与类型必备，责任者、其他题名、档号、收藏者地点/名称、形成日期及页码有则必备；电子载体/路径必备，标识符可选。类型 `[A]`，不与会议析出混淆；形成时间不是数字化上传时间。
- **地图**：8.13及表13（页21），图书/析出形态按8.2/8.3；其他地图的题名与类型必备，责任者、其他题名、比例尺、版本、出版地/者/年有则必备；纸质单幅地图的尺寸必备，电子载体/路径必备、标识符可选。类型 `[CM]`，比例尺在类型标识前，尺寸在出版信息后；不能仅用图像像素数替代纸质幅面尺寸。

## 数据集、预印本、程序与数据库

| 对象 | 规则与边界 |
| --- | --- |
| 数据集，8.14及表14，页22 | 图书/析出/连续出版物形态先按8.2—8.5；其他数据集题名、类型、引用日期必备；责任者、其他题名、发布/修改日期有则必备；版本可选，发布平台为电子资源可选；电子载体/路径必备，标识符可选。使用 `[DS]` 及真实载体，版本后接平台、圆括号日期、方括号引用日期，再接路径及标识符 |
| 预印本，8.15及表15，页22—23 | 题名、类型、引用日期及路径必备；责任者、其他题名、版本、创建/修改日期有则必备；电子载体必备，出版平台及标识符为电子资源可选。使用 `[PP]` 及真实载体；版本、平台、两类日期和路径分开，不能冒充已发表期刊文章 |
| 程序、数据库、汇编，附录A表A.1，页28 | 已确认类型代码分别为 `[CP]`、`[DB]`、`[G]`；载体按A.2（页29）。第8章未另设这三类的独立项目表，不能凭代码造一份“国标专用必备字段表”。先判断实际所引对象：程序本体、数据库整体、其中数据、使用手册或介绍网页各不相同；数据集按8.14、手册按图书、实际网站/网页按8.11等适用条款处理。仍无法归入明确形态时，记录真实责任者、题名、版本、路径等已知信息，并标明项目适配及待核对，不能声称已完整匹配专门条款 |

**标准示例存在差异**：8.11.3.2例5（页19）将软件获取页面示例标为 `[CP/OL]`，附录B.10例13（页37）对应示例标为 `[EB/OL]`。两处都已读到，不能据其中一例宣布另一种代码普遍错误。按实际所引对象区分，仍有歧义的条目标明，不把本页解释冒充已取得官方勘误。

数据集与预印本都不能省略必备引用日期；数据集版本“可选”和预印本版本“有则必备”分别保留，不把两者统一成同一规则。

## 特殊情况与版本

| 情况 | 依据及处理 |
| --- | --- |
| 无署名或责任者不明 | 7.1.3，页4：通常可记佚名/对应词；顺序编码制可省主要责任者，直接以题名起录。不根据网址、保存者猜作者。专利等专条另列必备责任者时，不能用一般省略规则掩盖尚缺的必备身份 |
| 团体作者 | 7.1.4，页4：根据所引资源记负有责任的团体名称；非汉字团体层级由上到下、层级间用句点，汉字名称按条款例外，不拆成虚构个人 |
| 无题名、多个合订题名 | 7.2.1—7.2.2，页4—5：无题名可据资源内容自拟并加方括号，明确为描述性题名；同责任者多合订题名列前3个，不同责任者可取首个或显著者；不著录并列题名。不为形式完整捏造正式题名 |
| 多卷本 | 7.2.3，页5：分卷书名、卷次、册次归入其他题名信息；引用具体卷时保留可识别该卷的信息，不能把卷次塞进版次或省去后仅留总书名。来源无整套/多卷页码合并规则时，不造全套页码范围 |
| 译著、章节译者与编者 | 8.2表1及8.2.2、8.3表2及8.3.2，页8—10：保留作者与其他责任者的角色；整书译者位于类型后、版本前，章节译者在析出部分并置于 `//` 前，容器编者属于容器一侧。不替换作者、不混译本与原版出版年，不猜未记全名 |
| 不同版次或载体 | 4.1—4.4（页2）、7.3—7.4（页5）：以实际使用资源及其题名页/版权页等确定身份、版次和载体。第一版可省，其余版本说明应记；预印本、正式发表本、译本或修改版的页码和元数据不可交叉拼接。确实用了不同版本时分别核对，不能只因标题或DOI相关就合并；同一资源仅换下载位置也不自动生成另一条文献 |

## 非连续页码的核查结论

已复查6.2（页3）、7.7（页7）、8.3示例（页10）、8.5.1及8.5.3（页11—13）和附录B中的相关条目。6.2明确短横线用于起讫页码，但未找到专门规定非连续页组必须用逗号或加号的文字；网络检索也未取得可归属正式条款的新依据。这是本次查到的证据边界，不宣称该问题在所有文件中都无规定。

- 根据出版者真实题录保留各段页码，不丢末段，不把间断页改成连续范围；不得自动将任意“+”全局替换成逗号。
- 有出版者记录支持时可统一该条目的表达，注明来源；没有则保留待核对，不新增国标强制规则。
- 8.5.1.3的分号用于连续文章各部分信息，9.2.1.2的逗号用于多篇文献的引文序号，都不能拿来证明非连续页码的分隔方式。
- [导出专项](citation-output-validation.md)只证明所测处理器如何输出某个页码输入，不证明该符号因此获得国标依据。

## 使用范围

本页补齐的是所列来源与判断步骤；自动脚注、任意数据映射、CSL整体合规及整篇论文仍不默认通过。其他任务采用不同模板时只保留其外观；题录规则仍须确认任务选定标准。
