# 校徽组合标识复用：有限 WPS 实测

## 对象身份与来源

格式参考为浙江大学工程师学院研究生论文 DOCX 格式母版。本轮找到的对象是一张校徽与学院名称组成的 PNG，位于该文件的规范说明首页；后面的“学位论文封面格式”示例页没有这张组合图，但**另有独立校名字样和圆形校徽**，此前遗漏已更正，实际封面复用见[封面专项](thesis-cover-validation.md)。因此本记录证明该现有图片对象可以按其原排布复用，不证明所有学位论文封面都应添加该标识。实际采用位置须有所选模板或用户要求作为依据。

公开包不附带这张标识图片。内置参数不能代替原图；需要复用时须取得所选来源中对应的图片对象，不截屏重建、不擅自下载其他版本替换，也不将其他母版改成这里的尺寸。

## 所查实际设置

| 项目 | 来源对象 |
| --- | --- |
| 图片资源 | PNG，551 × 147 像素，含透明通道；校徽和文字是一张完整图片 |
| 显示尺寸 | extent 为 3347739 × 893135 EMU，约 9.299 × 2.481 cm；WPS 显示宽 9.30 cm、高 2.48 cm |
| 比例与裁切 | 纵横比锁定，所查无裁切、旋转或额外效果；不拆开重排图内文字 |
| 环绕 | 嵌入式 inline，随所在段落排布；不是浮于文字上方或固定页面坐标的对象 |
| 位置来源 | 所在段落居中，保留其之前空段、段落属性及页面边距；没有独立的页面绝对 x/y 坐标，不凭截图反算后另设坐标 |
| 清晰度边界 | 按原显示尺寸约 150 PPI；属于源图本身的像素限制，不能称为高清矢量图或用提高标称 DPI 代替真实细节 |

EMU、像素和 PPI 用于识别来源及排查；最终仍检查 WPS 中 DOCX 的显示。WPS 保存可能对尺寸小数作极小舍入，实际显示无偏差时不为 XML 数值一致反复调整。

## 复用与验收步骤

1. 连同图片关系、原图、所在段落和影响位置的前方段落复用；保留所在节的页面及边距。只复制图片而丢掉段落排布，不能保证同一位置。
2. 在独立样稿中用中性文字替换其他内容，保留图片原尺寸和嵌入式排布；目标文档采用该对象须先确认适用位置，不把规范说明首页误当成通用学位论文封面原型。
3. 对照来源首页的固定参考副本，检查相同缩放下的位置、比例、边缘、图内文字及周边空白；发现实际偏差再定向修正，不任意改浮动定位或用空格推图。
4. 在 WPS 另存 DOCX，确认关闭并从磁盘重开；选中图片核对尺寸，再看正常显示和 100% 缩放下是否裁切、遮挡或失真。必要时检查保存后的原图资源是否被重新压缩，这只是辅助证据，不取代实际显示。

## 本轮结果

环境为 Mac WPS 教育版 12.1.25867。使用独立中性样稿和仅保留母版首页的参考副本，完成实际保存、关闭和磁盘重开：

- 重开后 WPS 图片工具仍显示宽 9.30 cm、高 2.48 cm，纵横比锁定；所查位置、比例、完整性和周边排布与参考首页一致。
- 所查 75% 同缩放图像区域与参考一致，100% 显示未见新增裁切、遮挡或可见退化。保存后原图资源字节未变，551 × 147 像素保留；这是保持源图质量，不是提高原图分辨率。
- 来源和保存后均为嵌入式居中段落中的图片；所查 WPS 页面显示符合原排布。本轮未通过环绕下拉菜单取得独立的选中项读数，环绕类型依据来源/保存属性辅助核对及实际页面显示，不声称完成其他环绕方式的交互测试。

完整母版参考副本打开时曾超时并回到首页，未据此认定完整母版通过；后续使用独立的首页参考完成本对象对照。没有导出 PDF、修改母版或论文稿。样稿页数和节数不是通用规则。

## 保留的限制

真实打印、放大输出的细节质量、其他 WPS/系统、浮动环绕变体、长题名或其他封面结构、完整封面及母版尚未通过本实验。原图内文字的字体身份不能由栅格图外观证明。已有前置页缺字体问题仍按[编号组合保留项](front-numbering-validation.md)另记，本图像通过不使其他文字字体自动通过。
