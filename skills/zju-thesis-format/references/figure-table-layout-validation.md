# 长题注、图文位置与跨页表格实测

## 样稿与操作

在 Mac WPS 教育版 12.1.25867 中，独立样稿复用参考母版的嵌入式曲线图对象及其所在段落、中英文图题、表题、普通正文和两列表格原型；使用中性验证文字，延长题注及表格内容。按已记录的明确标注应用题注五号、单倍和适用表线 0.75 pt；保留对应字体、对齐、首行缩进、网格、列宽及表格缩进，不因文本变长重设。

完成实际另存 DOCX、菜单关闭并确认回到首页、从磁盘保存文件重开，再检查页面、段落/字体面板及真实表格边框；结束时关闭样稿。本轮不导出 PDF，不覆盖母版或论文。原文件、图像、样稿和截图不发布。

## 通过范围

| 所查对象 | 保存关闭重开后的实际观察 | 结论 |
| --- | --- | --- |
| 中英文长图题 | 多行自然换行，段落面板均为单倍；所查中文题注字体面板为仿宋 / Times New Roman、五号、常规，没有因长度自动缩小字号；图题文本完整可见 | 所查多行题注有限通过 |
| 图片、图题及后续正文 | 原嵌入式图片位于长图题上方，中英文图题依次位于图片下方，正文接续其后；没有重叠、遮挡或可见裁切，重开后布局保持 | 所查嵌入式原型及当前位置有限通过，不推广为所有浮动原型或页末情形 |
| 长表题与表格 | 长表题在表格上方自然换行；单倍、五号及原首行缩进保留，未归零；表格在下方接续 | 所查长表题有限通过 |
| 两列表格原样跨页 | 保留允许行跨页设置；页间出现同一行文字接续，断点处续行、后续行序、末行及表后结束段均可见；重开后分页布局保持 | 所查行内跨页及普通多页表格有限通过，不代表禁止断行或复杂合并表通过 |
| 表内格式及边线 | 代表正文段落仍为 1.5 倍；选中实际表格后边框面板显示“表格 / 自定义 / 0.75 磅”；可见横线保持，编辑虚框不当作实际边线 | 所查表内行距及整体边线有限通过 |

辅助回读确认验证文字、表格行/单元格内容及图像资源保留；图像内部尺寸字段有微小舍入，页面无可见影响，未为 XML 数值完全一致反复调整。验收依据是 WPS 中实际格式与重开显示，不要求内部序列化一致。

## 常规处理步骤

- 长题注先沿用对应段落自然换行，核对字号、单倍、对齐、缩进和最后一行可见性。不要为缩短题注擅自缩小字体、改行距或插入固定空行。
- 图文顺序与图像对象类型一起检查：本轮是原嵌入式图片及其后题注，保留原段落。不同浮动锚点、环绕、组合图或页末拆分须按对应对象检查，不能套本轮的屏幕位置或间隔。
- 跨页表格逐个查看页尾与下页页首，确认续行、行序及末行未丢失或遮挡。允许行跨页不等于文字被截掉；先核对该行设置和实际续行，再判断是否需要改变断行。
- 核对适用表线时同时检查表级边框与单元格覆盖，避免只改局部而漏掉继承的上下边线。0.75 pt 来自明确标注，不把表格底层样式的旧 0.5 pt 误作新默认。
- 来源原型未标记重复表头；本轮没有新增重复表头、自动续表题、续表编号或手动拆表。需要这些功能时先确认要求，作为另行适配验证，不追认为母版默认格式。

## 仍未覆盖

所查浮动原型与页末绑定修复已另有[后续专项有限通过](floating-caption-validation.md)，不扩大本轮范围。其他浮动图片与文字环绕、复杂组合图、多图共题、单条题注超过整页、不可断长英文/公式混排，以及复杂合并/嵌套表格、超高单元格、禁止行跨页、重复表头、自动续表题及任意重排，未在本轮建立通过证据。完整母版、真实论文、其他 WPS/操作系统、打印和 PDF 输出亦不因此通过。

本轮没有发现所查设置在保存重开后失效。样稿页数、断点行号、文本长度与表格行列数仅为实验条件，不作为通用排版规则；新稿仍检查自己的实际分页。
