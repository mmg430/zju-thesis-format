# 浮动图片与页末图题绑定实测

## 范围与依据

2026-10-23，macOS、WPS Office 教育版 12.1.25867。以独立 DOCX 复用母版对应图片与题注，完成 WPS 另存、关闭、从磁盘重开；未导出 PDF。以重开后的实际显示为验收，XML 仅辅助记录对象属性。

| 对象 | 处理与观察 | 结论 |
| :--- | :--- | :--- |
| 普通位置浮动图 | 保留母版同段图像/中文题注、后续英文题注；保留相对段落锚点、紧密环绕及原图大小，重开后图在题注上方，无可见重叠或裁切 | 所查原型有限通过 |
| 页末浮动图 | 相同原型在页末空间不足时移至下一页，图片、中英文题注及后续正文顺序正常；未改变浮动属性 | 所查位置有限通过，无需修正 |
| 页末行内图 | 修正前复现图片留在前页、题注进入后页；仅增加下述分页绑定后，图片和中英文题注移至同页，保存关闭重开仍保持相邻，无可见遮挡 | 定向修正后有限通过 |

## 正常处理步骤

1. 先复用对应原图、尺寸、所在段落、锚点、环绕及题注字体、字号、单倍行距、缩进和对齐，查看实际页末位置；不能仅凭题注出现在下一页便认定分离，需同时查看前页图像。
2. **行内图片实际与题注分离时**，给图片所在段落设置“与下段同页”；中文题注设置“段中不分页”和“与下段同页”，英文题注设置“段中不分页”。最后一条题注不继续绑定无关正文。单语题注按实际链尾处理。
3. 这是为保留图题关系而采用的局部分页适配，不是母版原有默认；不全局套用，不借此更改字体、行距、尺寸或强加固定空行。
4. 所查浮动原型原样即可保持图题关系，不转换为行内、不改环绕或锚点。其他浮动对象若实际重叠，先定位锚点、相对位置及环绕影响，再在副本定向处理、重新实测；本轮没有建立其他浮动修复方案的通过证据。
5. 保存、关闭重开，核对完整图像、中英文题注、页间边界及后续正文。符合母版实际格式即可判所查对象通过。

## 属性与验证边界

所查浮动原型约 6.04 × 3.01 英寸，水平相对栏偏移 138520 EMU、垂直相对段落偏移 49802 EMU，紧密双侧环绕；保留母版已有 behindDoc / allowOverlap 设置。这些是对应原型来源属性，**不是所有图片的默认值**，也不据此要求新图置于文字下层。实际显示没有遮挡，不为了 XML 表示完全一致反复调整。

复杂组合图、多图共题、其他锚点/环绕原型、超过一页的图题整体及其他环境仍未验证。题注与图片尺寸变化后须重新查看实际分页；不沿用样稿页数、页码、占位段落数或位置。栅格图内字体身份、本轮未覆盖的字重字符及打印/PDF 不新增验证。公开记录仅保留方法和有限结果，不附母版、样稿、图片或本地证据。
