# 字体、字号与颜色逐对象核对

## 范围与状态

2026-10-24，对格式参考 DOCX 的正文、表格、说明文本框、样式/字符样式、主题、编号、引用的页眉页脚及公式声明作只读属性核对。说明首页、论文前页、目录、正文、图表、书目与附录分别定位；空白 run 和段落标记不混作可见内容。兼容分支中的同一说明框只作为同一对象的两种表示，不算独立证据。

**初次为源属性与标注核对；后续有限 WPS 实测见末节。** 旧专项的有限结果仍按其原对象、字重和字符范围有效；本页属性表不整体标为 WPS 已通过。原母版和论文未修改，公开仅记录格式属性与功能定位，不附原文、文件或本地清单。

## 采用规则

- 按实际内容、占位内容、明确指向填写内容的标注、纯说明分别处理。标注自身的字体/颜色不是填写内容的要求；“加黑/加粗”按字重理解，不据此补造 RGB 黑色要求。
- 同时保留 `ascii/hAnsi/eastAsia/cs`、主题引用、`sz/szCs`、字符样式及直接覆盖。中文/普通文字字号和复杂文种字号分开；不能把后者或空白标记字号覆盖到可见文字。
- 下表字体为对应原型声明及继承依据，不是 WPS 实际调用证据。主题与直接字体共存时保留来源层次，不能只用一个扁平字体名代表实际渲染。
- 未单列颜色不等于显式黑色，也不等于源文件写了 `auto`。保留对应继承或缺省状态；显式颜色、主题色、高亮、底纹、图形线色分别处理，不全篇清色或刷黑。

## 内容对象的字体与字号

TNR 为 Times New Roman；下表为常用文字字号，脚本差异和局部覆盖仍按原对象保留。颜色“未单列”指所查可见内容沿默认值及实际引用样式未取得单列颜色，并非对 WPS 显示颜色的推断。

| 对象 / 功能定位 | 字体与字号、采用方式 | 源颜色及边界 |
| --- | --- | --- |
| 规范说明首页大标题 | 微软雅黑 / TNR 36 pt；机构说明另有仿宋 / TNR 18 pt | 未单列；属于规范说明首页，不作为论文封面标题 |
| 论文封面分类/保密字段与代码 | 标签有仿宋_GB2312 / TNR 12 pt，部分代码及说明为宋体 / TNR 10.5 或 12 pt，按对应 run 复用 | 显式 `000000` 与未单列并存，不整体覆盖；占位提示与实际填写区分 |
| 封面学位类别大字 | 仿宋 / TNR 24 pt | 显式 `000000` |
| 封面中文题目、中文题名页题目 | 按明确标注仿宋 18 pt 加粗；示例占位文字为 16/12 pt 或 14 pt，不能当作填入内容字号 | 占位 run 有未单列及显式 `000000`，保留对应来源，标注未另规定颜色 |
| 封面英文题目 | 按明确标注 TNR 16 pt 加粗；标注文字自身有 12 pt | 未单列与显式 `000000` 分段存在，不能把说明自身格式整段复制 |
| 姓名、导师与专业/学院等字段 | 对应仿宋 / TNR 14 pt；姓名/导师明确四号仿宋；封面日期有 15 pt，题名页签名/评阅等字段有 14 pt | 多数字段显式 `000000`，日期/部分签名未单列；不同字段不强制统一字号 |
| 声明与授权标题 | 方正小标宋简体 / TNR 15 pt | 未单列；不把该东亚字体换成普通章标题仿宋 |
| 声明与授权正文、签名日期 | 仿宋 / TNR 14 pt | 未单列；不套普通正文 12 pt，仍无完整前页字体实测保证 |
| 致谢、中文摘要、附录的标题/正文 | 标题仿宋 / TNR 15 pt 加粗；正文按明确标注仿宋 / TNR 12 pt；关键词对应 12 pt | 所查常用原型未单列；说明自身及空白标记不能新增正文局部字号 |
| Abstract 标题/内容/关键词 | 标题 TNR 15 pt 加粗；内容及关键词按标注 TNR 12 pt；标题保留原东亚方正小标宋简体声明 | 未单列；旁边 14 pt 说明不是摘要内容字号 |
| 目录及图表目录标题/条目 | 标题仿宋 / TNR 15 pt 加粗；章级标签 12 pt 加粗，引导符/页码对应 14 pt 常规，节级 12 pt；符号局部声明另留 | 条目多数显式 `000000`，有未单列片段；标题未单列，不全段刷同一字符格式 |
| 常见章/一级节/二级节标题原型 | 分别仿宋 15 pt 加粗、14 pt 加粗、12 pt 常规；西文按对应 TNR 声明 | 所查常见原型未单列；其他节标题例外见下表，不能由常见原型强制统一 |
| 普通正文 | 仿宋 / TNR 12 pt；部分 `szCs=22` 即复杂文种 11 pt，不与普通 12 pt 混同 | 所查常用原型未单列 |

| 表内文字/符号 | 常用仿宋 / TNR 10.5 pt；局部符号有 Segoe UI Symbol 或宋体声明 | 所查内容未单列；不能只复制表格底层 Calibri/宋体样式，不能覆盖符号 run |
| 图内可编辑标注 | 明确说明常用仿宋 / TNR 10.5 pt；个别照片文本框实际普通字号 12 pt、复杂文种 10.5 pt，须保留原属性并单列与通用标注的差异，不静默统一 | 所查可编辑文字未单列；栅格图中文字的字体、字号和颜色无法据 DOCX run 反推 |
| 参考文献标题/条目/编号 | 标题仿宋 / TNR 15 pt 加粗；条目仿宋 / TNR 12 pt，局部复杂文种 10.5 pt；编号级 TNR 12 pt | 普通条目未单列，条目中的实际超链接另有主题蓝色，不把说明色应用到书目 |
| 页眉与页脚页码 | 所查样式及覆盖为 9 pt；部分页眉宋体直接声明，其他按主题/样式继承；页码保留自身字符样式 | 未单列；不把一节的直接宋体设置当作所有页眉页码的唯一字体 |
| 书脊文字、作者简历标题 | 书脊原型仿宋 / TNR 14 pt，简历标题 15 pt；不由标题推定尚无内容的简历正文 | 未单列；图像校名/校徽不当可编辑字库 |
| 公式及脚注/尾注 | 数学设置指定 Cambria Math；所查公式有 Cambria Math / 宋体 / TNR 脚本声明，保留公式结构，字号还受公式层级影响；脚注/尾注部件只有分隔标记，没有可据以采用的实际注释正文 | 不从公式周边正文推造全部数学字号/颜色；无实际脚注条目不宣称已提取完整脚注配置 |

## 必须保留的原型例外

- 源正文对象 B234、B237 的一级节标题可见文字使用宋体 14 pt（西文 TNR）；B246 还有仿宋/TNR 的段内差异。B175/B225/B231 中也有局部宋体片段。以上是原型差异，不是字体缺失的证明；无针对这些对象的明确统一标注，不擅自换成仿宋。常见一级节标注对应仿宋原型，不推定覆盖全部例外。
- 摘要说明、封面题目提示、示例正文、图片可编辑标注及其段落标记都有不同字号。按明确指向填入内容的标注采用时，同时登记原属性和采用方式；没有明确对应时保留原对象并标明差异。
- 字体声明只说明 DOCX 的请求。缺字体、主题映射或字符回退仍须在实际 WPS 环境检查；本轮不安装字库，也不新增嵌入/调用通过结论。

## 颜色定位与说明边界

| 源颜色 | 所查位置与含义 | 处理 |
| --- | --- | --- |
| `000000` | 封面部分字段、目录条目和英文题注等的显式文字色 | 只保留对应 run，不推广到全部正文 |
| `hyperlink`，备用 RGB `0563C1` | 说明框中的参考链接，以及书目示例内的实际链接字符样式 | 保留主题引用与备用值的来源关系；不把说明链接带入论文，也不据其蓝色把整条书目染蓝 |
| `333333` | 书目编排说明的一个小标题，同时有白色底纹 | 是说明自身格式，不是参考文献条目颜色要求；底纹与文字色分开 |
| 未单列 | 多数正文、标题、中文题注及页眉页脚等 | 保留继承/缺省；不能把它登记为明确 `000000` 或明确 `auto` |

主题中还定义有已访问链接色及其他调色板项；调色板存在不等于内容实际采用。所查实际文字及说明中没有取得“全文统一黑色”的明确依据，不新增该规则。颜色显示的有限实测见下节；精确主题色数值、链接访问态及新增对象的实际字库身份仍未验证。


## 独立样稿 WPS 保存关闭重开检查

剩余前页字段、声明标题/正文、说明深灰、学位类别大字等未完成本轮逐项重开面板核对；未覆盖字重/字符、符号、图内文字与真实字库映射仍沿原限制。检查中遇到活动文档切换时停止该项，不将其他文档面板当作样稿证据。

复用时选择源对象的实际对应片段，尤其保留超链接中的字符样式与段内差异；只取同段的首个链接或首个 run 可能漏掉实际带主题色的片段。测试文字、页数和对象顺序均不成为通用参数。
