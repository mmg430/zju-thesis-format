# 有限字体实测记录 — 2026-10-23

以下为维护者在Mac WPS教育版12.1.25867中进行的独立样稿实测摘要。原母版、截图、DOCX/PDF、字库及私有日志不公开，公开读者无法逐项独立复核该私有实验，须对自己的稿件重验。本摘要不声称完整论文或其他平台通过。

## 通过的方法及范围

| 项目 | 维护者实际观察 | 可复用方法与边界 |
| --- | --- | --- |
| 仿宋、宋体、Calibri | 未补齐原字库时直接/主题声明存在替代；按授权补齐内部名称匹配的FangSong5.01、SimSun5.03、Calibri Regular6.26后，实际绘制字符调用对应字库、嵌入、字形/字宽及检索通过；单独诊断稿无缺字体提示 | 保留声明、主题与覆盖，核对内部名/版本/实际字符，不把旧替代family写回正文 |
| Cambria样式声明 | 上述处理后综合样稿仍提示；对照定位到heading 2及链接字符样式的ascii/hAnsi=Cambria，两处各自保留均能维持提示；仅去掉这两处属性的诊断稿无提示 | 删减仅用于定位，不作为修复，不删除母版样式或改成TNR |
| 补齐Cambria | 按授权安装含Cambria Regular/Cambria Math Regular1.02的集合并重启WPS后，保留全部声明的综合样稿经实际另存、确认关闭、重开和普通PDF导出，无缺字体提示 | 单字体稿另验证Cambria Regular1.02的实际嵌入、测试字形/字宽及检索；不代表Cambria Math公式或其他字重通过 |
| 最终综合输出 | 对应文字及同尺度逐页渲染与原基线一致，所查分页/页眉页码/图表正常；实际字体、嵌入流、ToUnicode、渲染无警告及中文/符号短词检索通过 | 仅针对夹具内容，不推广固定页码；静态页眉不证明跨章自动映射 |
| Segoe UI Symbol及其他符号 | 补齐原声明同名字库后，所查符号原生封装/字形/检索通过 | 不把所有符号统一改为Segoe；逐字符核对对应声明 |
| 照片中的可编辑标注 | 文字可检索但不可见，经单因素框高调整恢复显示，保留字体/字号/位置后往返通过 | 属项目对象适配，不概括成图片遮挡，不套固定框高 |

未用Calibri对照保留声明而不触发，说明不能笼统要求“清理所有未用样式”。删除替代别名或精简字体表未解决本次Cambria触发，不写为通用修复。

## 异常、失败与未知

首轮导出曾出现标题横向偏移；磁盘仍保留居中样式，操作中出现未保存状态/关闭对话框，原因未确认。重新从磁盘打开后恢复，最终再次另存、确认关闭、重开和导出与基线逐页像素一致。没有采用显式居中改写，不将异常归因于字体安装或宣称某种缓存修复已验证。快捷键调用不等于窗口已关闭。
