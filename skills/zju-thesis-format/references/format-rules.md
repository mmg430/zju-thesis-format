# 来源与适用边界

## 格式参考

本项目排版方法参考浙江大学工程师学院研究生论文 DOCX 格式母版。母版的官方发布身份、版次和对具体专业/学位类型/提交批次的现行适用性未由本仓库独立核实。它用于建立和核对格式复用方法，可作参考，不构成全校通用或现行合规认证。

公开包包含从母版实际属性提取的内置排版参数，供直接使用；不公开原始DOCX或正文摘录。使用内置方案不依赖维护者项目或源母版。需要其他格式时，使用者提供自己有权使用并确认适用的模板。

## 当前任务如何确定依据

直接使用模式以[内置排版方案](builtin-format.md)和用户确认的适用要求为依据；自定义模式以用户指定的DOCX模板及适用规范为依据。实际属性、明文说明、社区模板实现及项目技术适配分别记录；不能相互冒充，也不自动推断现行学校要求。实际格式与说明冲突时取得用户已有选择，未知项局部标明。

本版不从历史参数自动补齐格式，也不回退到旧配置。公开包不分发用户DOCX、论文或验证截图，使用不依赖外部私有文件。

社区模板只作实现参考，见[固定版本来源](zjuthesis-comparison.md)；字体和WPS试验见[有限实测摘要](font-validation-2026-10-23.md)。本工具不是学校、学院或WPS官方模板，没有现行合规认证。
