# 封面、题名页、声明与预留页

## 来源和采用范围

参考浙江大学工程师学院研究生论文 DOCX 格式母版。以下为实际对象及明确填写标注的格式配置；2026-10-24 已回查源属性。字体简写 TNR 为 Times New Roman，1 pt = 20 twip。普通文字与复杂文种的字号、直接格式与继承分别保留，完整规则见[字体字号颜色](font-size-color-audit.md)。

四类页面均纳入 skill：论文封面（含独立校名、校徽）、中文题名页、独创性声明及版权授权书、致谢及作者简历预留。它们不是同一个章标题/正文样式；不能整页刷成正文仿宋小四。页面沿用[内置页面参数](builtin-format.md#页面)，保留各对象空段、分页/分节、下划线及锚点。作者简历按所选稿件结构保留其位置，不因本页分类移到致谢之后，也不固定预留页数。

## 字体、字号与文字颜色

“未单列”表示来源未取得对应可见文字的独立颜色声明，保留继承/缺省，不自动补 `#000000` 或 `auto`。加黑表示加粗，不是新增色号。说明框及占位提示自身的字体/颜色不作为填入内容要求。

| 页面及对象 | 字体、字号和字重 | 文字颜色与边界 |
| --- | --- | --- |
| 封面分类/保密字段、代码 | 标签有仿宋_GB2312/TNR 12 pt；代码及说明有宋体/TNR 10.5 或 12 pt，逐片段保留 | 显式 `#000000` 与未单列并存；不能把说明文字变为提交内容 |
| 封面学位类别大字 | 仿宋/TNR 24 pt，保留原字重 | 显式 `#000000` |
| 封面中文题目、中文题名页题目 | 按明确填写标注：仿宋 18 pt、加粗；西文保留对应 TNR 声明 | 题目原型有未单列片段，说明有显式黑色；不由说明推造全文题目色号。保留对应下划线 |
| 封面英文题目 | 按明确填写标注：TNR 16 pt、加粗；保留脚本差异 | 未单列与显式黑色片段分开保留 |
| 封面姓名、导师、专业等信息 | 仿宋/TNR 14 pt，原标签与填写区分别保留下划线、字重 | 对应多数字段显式 `#000000` |
| 封面提交日期 | 仿宋/TNR 15 pt、加粗，日期填写处保留单下划线 | 未单列，不随姓名字段改成四号或强设黑色 |
| 中文题名页作者/导师签名字段 | 仿宋/TNR 14 pt、加粗 | 未单列 |
| 中文题名页评阅、答辩委员字段 | 仿宋/TNR 14 pt，原字重与签名标题分开；答辩日期 14 pt 加粗 | 所查对应字段显式 `#000000` |
| 独创性声明、版权授权标题 | 方正小标宋简体/TNR 15 pt，原型未直接开启普通加粗，保留继承 | 未单列；不套仿宋章标题，不为外观相似换字库 |
| 声明及授权正文、签名与日期 | 仿宋/TNR 14 pt；正文局部加粗及单下划线强调保留，其余不整段加粗 | 未单列，不套正文小四或说明深灰 |
| 致谢标题 | 仿宋/TNR 15 pt 加粗，章标题原型 | 未单列 |
| 致谢正文 | 按明确标注仿宋/TNR 12 pt、1.5 倍；原示例固定 24 pt 的差异已按标注处理 | 未单列；缩进和局部强调保留 |
| 作者简历预留标题 | 仿宋/TNR 15 pt 加粗，章标题原型 | 未单列；来源没有可据以采用的简历正文，不补造正文字体、字号、色号或固定空页数量 |

## 页面内部排布

下列为对应母版原型的实际段落值；字符单位与 twip 并存时一起保留，不相加换算，不以空格重新推位置。未列的行距或段距不从其他页面补齐。

| 对象 | 实际设置及复用方式 |
| --- | --- |
| 封面分类/保密栏 | 左对齐，1.5 倍行距；保留原制表位和逐片段格式 |
| 学位类别、提交日期 | 居中；校名、类别、校徽、题目、人员信息、日期按原段落顺序及空段排布 |
| 封面中文题目 | 段前 360 twip（18 pt）；leftChars=257 / left=977，hangingChars=112 / hanging=360；保留组合 |
| 封面英文题目 | leftChars=257 / left=617；不套中文题目悬挂设置 |
| 姓名、导师及多数专业信息行 | 1.5 倍；left=839 / firstLine=1141；合作导师另为 firstLineChars=707 / firstLine=1980，专业信息续行另有自己的缩进，不全行统一 |
| 中文题名页题目 | firstLineChars=750 / firstLine=2100；空段及题目下划线按原对象保留 |
| 题名页作者/导师签名 | firstLineChars=550 / firstLine=1546；导师签名行固定 20 pt，其他行未据此统一 |
| 评阅及委员行 | 固定 26 pt；各行缩进不同：首评阅行 left=839、firstLineChars=400 / firstLine=1120，其余评阅行 firstLineChars=700 / firstLine=1960；主席 firstLineChars=450 / firstLine=1260；委员第一、第二行 leftChars=400 / left=960、firstLineChars=470 / firstLine=1321；第三行 firstLineChars=800 / firstLine=2240；第四、第五行 leftChars=400 / left=960、firstLineChars=470 / firstLine=1316；不由一行生成全组统一缩进 |
| 题名页答辩日期 | 居中，固定 22 pt |
| 声明及授权标题 | 居中，snapToGrid=0；段前 beforeLines=100 / before=312，两种单位保留，不能相加；标题前后空段按对应页保留 |
| 独创性声明正文 | 1.5 倍；firstLineChars=218 / firstLine=610；局部强调、空段保留 |
| 独创性声明签名日期 | 固定 20 pt；left=960 / hanging=420，保留同段字段相对结构 |
| 版权授权正文、签名日期 | 固定 28 pt；保密附注另 left=480；不套声明正文 1.5 倍或普通正文 12 pt |
| 致谢及作者简历标题 | 章标题居中、段前 22 pt / 段后 12 pt、与下段同页、段中不分页；不凭“预留”增加空白页 |
| 致谢正文 | 采用标注的 1.5 倍、12 pt；firstLineChars=200 / firstLine=480 等其余原属性保留 |

## 实施与验证边界

复用对应页及对象 → 仅替换待填内容并移除说明对象 → 对照上述实际设置/明确标注 → 在 WPS 检查、定向修正、保存关闭重开。声明与授权的正式文字、签名及日期按实际提交要求处理，不从格式配置生成虚构签名或个人信息。

- 封面短中英文题目、校名/校徽排布已有[有限实测](thesis-cover-validation.md)；不代表所有前页字体已正确调用。
- 姓名字段字体/字号/黑色及所查标题例外的新增有限实测见[字体颜色记录](font-size-color-audit.md#独立样稿-wps-保存关闭重开检查)。日期逐项重开、其他前页对象和底层字库身份仍未完成。
- 致谢代表正文按明确标注采用 12 pt、1.5 倍的有限实测见[标注专项](annotation-format-validation.md)。作者简历正文未提供原型，不标为已验证。
- 中文题名页、声明及授权的以上新增排布清单属于来源属性核对，未经本轮逐项 WPS 实测；已有[无编号前页组合](front-numbering-validation.md)只证明所记编号适配，不替代字体和整页外观核对。
