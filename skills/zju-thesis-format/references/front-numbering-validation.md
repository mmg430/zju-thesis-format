# 前置页编号与正文重启：有限 WPS 实测

## 来源与适用边界

格式参考为浙江大学工程师学院研究生论文 DOCX 格式母版。所查源文件各节没有明确的页码格式或起始值设置；页脚使用 PAGE 域。手工目录中出现的罗马数字只是条目显示，不能据此认定母版各节已经配置罗马编号或正文重启。

本轮按任务要求，在独立中性样稿中建立“前置页使用大写罗马数字、正文改用阿拉伯数字并从 1 开始”的**编号技术适配**；保留母版已有页面、字体、段落、页眉横线和 PAGE 页脚外观。它不是新增的母版默认参数，也不是学校统一编号要求。实际项目先确认其适用编号方案，不默认改号。

## 已完成的操作

在 Mac WPS 教育版 12.1.25867 中，使用包含致谢、摘要及续页、多页目录和两章正文的独立样稿：

1. 在前置编号段和正文之间分节；需改变页眉的前置部分及后续正文章也分别设节，不用普通分页符代替编号边界。
2. 前置首节明确大写罗马编号并从该编号段的起点开始；后续前置节延续，不逐节重启。本轮起点为 I，仅是此次适配选择。
3. 正文首节明确阿拉伯编号并从 1 开始；后续正文节继续前节，避免每章误从 1 重启。分节与页码起点分别核对，不因增加新节就默认重置页码。
4. 保留 PAGE 域及页脚字体、位置和继承。页码格式/起点与页眉页脚的“链接到前一节”是不同设置；不要为重启页码而无差别切断所有链接。静态页眉按对应节更新文字，续页和相邻节一并检查。
5. 在 WPS 中更新整个目录，检查前置条目显示罗马页码、正文条目显示重启后的阿拉伯页码。按[目录方法](automatic-toc-validation.md)恢复实际偏离的字符格式，保留已对齐位置；标题和层级未变时只刷新页码。
6. 另存 DOCX，确认关闭，再从磁盘打开；核对前置连续编号、前置与正文边界、正文首节重启、后续正文延续、目录页码及对应页眉页脚。目录链接另抽查实际落点。

本轮没有导出 PDF，不要求 XML 一致性。节属性读取只用于排查编号方案，不代替上述 WPS 实际检查。

## 有限通过结果

| 对象 | WPS 保存关闭、磁盘重开后的观察 |
| --- | --- |
| 前置编号 | 致谢、摘要及续页、目录及续页的大写罗马编号连续，新增前置节未误重启 |
| 正文重启及延续 | 正文首章从阿拉伯 1 开始，续页和后续章连续，未逐章重复重启 |
| 目录页码 | 前置条目保留罗马编号，正文条目与重启后的实际页脚相符；多页目录在修正后仍保留对应显示 |
| 页眉页脚 | 所查致谢、摘要及续页、目录、两章正文的静态页眉与所在节对应；PAGE 页脚位置及字体外观未见偏移 |
| 链接 | Command 单击致谢、摘要和正文首章目录标签，实际到达相应标题及编号页；未逐一点击全部条目 |

已发现的完整目录更新字号偏差按既有方法修正后通过，不继续记作本轮 DOCX 未解决项。样稿页数、条目数、章起页和页码值只用于本地定位，不是通用规则。

## 仍未覆盖

封面/声明完整格式与字体身份、不同编号起点或小写罗马、多个重复编号段、首页/奇偶页不同、奇数页起章及空白页与编号的组合、图表目录、完整前置材料、完整母版或论文、其他 WPS 版本及操作系统，仍需按实际对象核对。此次静态页眉对应不证明 STYLEREF 动态章名自动映射。未做 PDF 检查不影响所查 DOCX 通过结论。


## 后续组合实验：封面与声明页不显示页码

独立中性样稿在同版 Mac WPS 中新增封面和声明占位页，复用母版对应段落的已有设置与字体声明，衔接上文编号方案。该实验只验证“不显示页码的前页 → 前置编号 → 正文重启”的组合；没有完整复原封面题名、说明图形、签名或声明法律文字，不证明完整封面和声明格式通过。

### 处理步骤

1. 将不显示页码的前页与首个编号前置页分节。本轮封面和声明各有独立节；目标文档是否需要分别设节，按实际页眉页脚差异确定，不照搬样稿节数。
2. 不显示页码的节使用独立空页脚，保留各节原有页面、边距和距离。不要在共享 PAGE 页脚中直接删除数字，否则可能同时影响后续编号页；本轮对应前页也使用空页眉，属于此样稿适配，不能作为其他母版的默认要求。
3. 在首个编号前置节明确接入有 PAGE 域的页脚，并设置已确认的编号格式和起点。不能只隐藏前页数字后仍继续累计，也不能让空页脚被后续节继承。本轮前置从 I 开始，所以不将封面和声明的物理页数计入该编号段。
4. 其后前置节连续编号；正文首节切换阿拉伯编号从 1 开始，后续正文节继续。页脚显示、编号起点、页眉文字与节间链接分别核对。
5. 更新整个目录，确认占位封面/声明没有误入目录，前置与正文条目的页码采用各自编号段。按已有目录方法恢复实际字号偏差，标题和层级未变时仅刷新页码；保存、确认关闭、磁盘重开后逐页检查边界。

### 结果与保留项

| 对象 | 本轮结果 |
| --- | --- |
| 封面与声明页码 | 重开后所查页脚均无可见页码，没有混入后续 PAGE 域 |
| 前置与正文编号 | 首个编号前置页从 I 开始并延续；正文从 1 重启，后章继续，无编号前页未使编号段偏移 |
| 目录与页眉页脚 | 完整更新、格式修正及页码刷新后，前置罗马页码和正文阿拉伯页码与实际页脚对应；所查编号页静态页眉仍对应所在节 |
| 跳转 | 重开后 Command 单击前置及正文首章目录标签，实际落点正确；未逐一点击全部链接 |
| 新增对象字体 | **未完成字体一致性验收**：保留母版中 `仿宋_GB2312`、`方正小标宋简体` 等原声明；WPS 仍显示缺字体标记，保存时提示使用云字体。具体触发项及实际字体映射未独立确认，不能仅凭外观判为同字体，也未自行替换或关闭提醒 |

编号组合通过与字体保留项分开记录，不把整个样稿称为全部格式通过。字体问题按[字体排查方法](pdf-font-output.md)另查；本轮没有新增字库安装、PDF 输出或字体身份通过证据。样稿页数、编号前页数量、节数和页码仅为实验条件，不作为通用排版规则。小写罗马、多重重启、首页/奇偶页与空白页组合、完整前置材料及其他环境仍未覆盖。
