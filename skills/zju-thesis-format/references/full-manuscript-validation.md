# 按任务验证与 WPS / PDF 验收

## 验证层级

| 本次任务 | 应取得的证据 | 未执行部分如何记录 |
| --- | --- | --- |
| 检查或提取格式 | 对应源版本的属性、继承、直接覆盖及缺口；不写入目标 | 标“XML 属性已核对”，不宣称渲染通过 |
| 在副本修改 DOCX | 修改范围及实际保存的文件；回读对象、样式、编号和节属性，核对非目标内容未被意外改动 | 若无 WPS，标“DOCX 已修改；WPS / PDF 未验证” |
| 验证 WPS 往返 | 应用版本、实际另存版本、确认关闭及重开后的对象/分页检查 | 没有导出 PDF 便不能声称输出验收通过 |
| 验证 PDF 输出 | 对应已保存 DOCX 的导出结果、物理尺寸、字体、嵌入、可见性和检索等 | 抽样须列明对象及检查范围，未覆盖项保留 |

按用户要求和改动影响选择检查范围，不把只读任务升级为排版修改。没有 WPS 能力仍可完成 XML 检查，但用户明确要求的 WPS 实测应报告未完成，不能以脚本或其他应用替代。

## 往返与输出方法

在取得单文件编辑权的副本上操作；先确认来源已完整保存并记录对应版本。实际另存新文件、确认窗口已关闭或回到首页、处理保存提示，再重开相同磁盘路径，核对标题和可见格式。仅按保存而文件未重写，不当作WPS写回证明；调用关闭快捷键不等于已关闭。

普通导出PDF并确认成功、输出文件名/目录/页范围；再修改则建立新版本证据。核对实际物理尺寸和文字层，不凭导出选项判通过。逐页核对分页、目录目标、页眉页码、题注/表格/图片、实际字体、嵌入、可见和阅读器中文检索；标明总览与放大检查范围。

自动目录须分开检查标题层级、完整更新与仅更新页码、更新后的条目格式、缓存页码及实际跳转；DOCX 与 PDF 交互各自取得证据。母版手工目录的新增域及样式属于适配，见[有限实测及失败项](automatic-toc-validation.md)。

保存可能合并run或重编号样式ID，应按样式名/继承和逐字符属性核对，不误称XML逐字不变。保留输入、实际另存版本、关闭快照和对应PDF。未通过的输出保留定位，不当作最终稿；不照搬历史页数、章起页、空白页位置、分表行数或图稿裁切比例。

[有限实测记录](font-validation-2026-10-23.md)只支持指定环境/对象的方法；不证明任意新论文、跨章自动页眉或完整交付已经通过。PDF内容只公开经审查的中性材料，不上传论文或本机诊断日志。
