# DOCX 在 WPS 中的格式验收

## 验收原则

以 **DOCX 在 WPS 中实际满足所选母版格式**为验收重点；内置模式以已记录的母版参数为准。核对页面、标题、正文、图表、目录、参考文献及页眉页码，并在保存、确认关闭和重开后检查实际显示与功能。XML 仅在提取设置或排查继承、字体、域等问题时辅助使用，不要求结构、样式 ID、run 划分或字节一致；无实际格式或功能影响的序列化差异不判失败。PDF 仅在用户要求导出、提交要求包含 PDF，或具体输出问题需要时检查；未做 PDF 检查不影响已有证据支持的 DOCX 验收结论，须分别报告范围。

格式来源先按入口确定：内置方案使用已记录参数，自定义模式使用本次选定模板的实际设置，不叠加其他方案。历史 XML 比较、PDF 像素对照和字体流检查是当时实验的辅助证据，不成为每次 DOCX 排版的必做项目。

## 按任务取得证据

| 本次任务 | 验收重点 | 结论范围 |
| --- | --- | --- |
| 只读检查或提取格式 | 对应版本的 WPS 显示、设置及缺口；必要时用 XML 查继承或覆盖，不写入目标 | 仅提取属性时标“属性已核对；WPS 实际格式未验证” |
| 在副本修改 DOCX | 在 WPS 中保存、确认关闭并从磁盘重开；按修改影响核对母版对应对象、实际分页与功能，确认未意外改变其他内容 | 可报告所查 DOCX 对象通过；无 WPS 实测则标“DOCX 已修改；WPS 未验证” |
| 需要 PDF 输出 | 从已保存版本导出，核对物理尺寸、文字层、分页、可见性、字体嵌入及检索；交互按需检查 | PDF 单独报告通过、失败或未检查，不用它代替 DOCX 验收 |

只读任务不升级为修改；没有 WPS 能力时可完成属性提取或辅助排查，但不能宣称 WPS 中已通过。PDF 未检查只表示该输出未检查，不使已通过的 DOCX 对象退回未验证。

## DOCX 保存重开与对象检查

在取得单文件编辑权的副本上操作，先确认来源已完整保存并记录版本。实际另存新文件、确认文档已关闭、处理保存提示，再重开同一磁盘路径，核对文件身份。调用保存或关闭快捷键不等于实际写回或已关闭。

按本次范围对照母版检查：

- 页面与分页：纸张、边距、分节、章首和跨页显示；不照搬样稿固定页数或空白页位置。
- 标题与正文：字体、字号、粗斜体、行距、段距、缩进和段内混合格式。
- 图表与书目：题注、编号、边框、对齐、续行及跨页，检查缺字、裁切和遮挡。
- 目录与页眉页码：层级、条目、实际页码、跳转、章名对应及保存重开后的稳定性；自动更新后重新核对受影响对象。

字体按母版对应对象保留；实际替代、缺字或调用不明处分别记录。WPS 提示可作为排查线索，不能仅凭有无提示判断全稿通过。需要定位时才查声明、样式、主题或其他 XML 属性；不为内部表示不同而反复改写无实际格式问题的文档。

自动目录的完整更新与仅更新页码需区分。母版手工目录新增域及样式属于适配；更新后检查条目格式及实际落点。本次 Mac WPS 的 Command 单击仅有有限证据，其他环境先验证实际跟踪操作；见[专项实测](automatic-toc-validation.md)。

## 按需 PDF 检查

用户要求导出、提交要求包含 PDF 或需要排查输出问题时，再普通导出 PDF，确认成功及文件、目录、页范围。核对实际物理尺寸和文字层，不凭选项判通过；按范围检查分页、目录目标、页眉页码、图表显示、实际字体、嵌入和阅读器中文检索。DOCX 与 PDF 交互分别报告；PDF 问题单列为输出问题，只有证据表明它源于 DOCX 格式时才回改文档。

## 记录与结论

注明所查版本、母版依据、对象、WPS 版本、实际观察和剩余限制。历史记录中的 XML 或 PDF 对照结论保留原实验范围；不将“属性已读取”写成“WPS 已验证”，也不将未做的 PDF 检查列成 DOCX 未通过。保存必要的版本与证据即可，无须日常保留完整 XML 差异或逐页 PDF 像素对比。

[有限实测记录](font-validation-2026-10-23.md)只支持所记环境及对象，不能证明任意文档或完整交付通过。公开结果不上传论文、个人路径或本机诊断日志。
