# 字体实际调用、嵌入与检索

先确定字体依据：内置模式使用[内置方案](builtin-format.md)记录的对应字体；自定义模式保留模板实际声明及继承。两者均先定位缺失对象。建立已知字体对照、直接声明、主题继承与未用声明等必要的隔离诊断；一次只改变待查因素。检查底层段落/链接字符样式，即使可见run有直接覆盖。诊断删除声明不等于可采用的修复。

本页用于实际字体、缺字或提示问题的定向排查，不是日常 DOCX 格式验收的全套必做清单。先在 WPS 中核对对应对象的显示和设置；需要追踪继承或触发项时再查 XML，PDF 项只在需要输出或排查导出问题时记录。

## 定位顺序

先建立定位表：对象类别、部件/样式/属性位置、字符脚本及字重、直接或主题声明、覆盖关系、实际使用证据、WPS 提示及状态；需要 PDF 时另列字体/嵌入结果。公开结果只保留格式与中性定位，不分享原文、个人路径或字库。

1. **文字实际对象**：查正文、标题、表格、页眉页脚、域结果、脚注及可编辑图内文字的 run 和字符样式；公式另查。逐字区分 ascii/hAnsi/eastAsia/cs、主题引用、字号及字重。段落标记的 rPr 不代表整段 run；栅格图不能靠 OCR 或外观确认字体。
2. **样式与编号链**：追踪实际引用的段落/字符/表格样式、basedOn 和编号级字形，单独检查关联字符样式。即使直接格式覆盖了字体，也保留底层声明为候选；已有 Cambria 有限实验说明此层可能触发提示，但不证明其他字体同样触发。
3. **默认值与主题**：解析 docDefaults、主题及脚本映射，再判断是否有文字落入对应分支。仅有 Jpan 映射中的 `ＭＳ ゴシック`、`ＭＳ 明朝` 不是当前文字调用或必须安装的证据；未做隔离实验时也不能断言它们绝不触发提示。
4. **其他声明**：最后查 fontTable、无引用样式及其他部件。只有在已检查范围内确认没有引用链，才标“未发现使用证据”，仍需说明覆盖范围；不能把全局搜索命中当成实际缺失，也不能仅因 PDF 中没有该字体就断定声明无关。

隔离定位必须使用独立诊断副本，一次只改一个因素，记录提示是否随之消失并做对照。诊断删除、清空字体表或删样式不自动成为可发布修复；源格式保留时优先核对同名字库是否存在、启用、内部名称及字符/字重覆盖。必要的结构清理须有使用关系证据和单独修改授权，随后复验。

`Courier` 与 `Courier New` 是不同 family，不能凭文件名或相近外观互认。源文件存在 Courier New 的字体表/未用样式声明，不足以要求安装 Courier，也不足以证明受限嵌入的触发项。字体诊断不自动下载、安装、改名、替换字体或删除主题。

## DOCX 字体复验与按需输出检查

有可用授权的同名字库时，核对内部family/PostScript名、版本、字符覆盖与技术嵌入属性，安装后重启 WPS，在新副本中实际另存、确认关闭、重开，核对对应文字的实际字体、字形及换行分页。PDF 导出及嵌入检查仅在需要该输出或排查输出问题时进行。不得改字体内部名、擅换字体或关闭提醒制造通过；不默认删除缓存或替代别名。[实测范围](font-validation-2026-10-23.md)。

需要 PDF 输出验收时，直接核验物理尺寸及文字层，普通PDF选项不保证结果。实际字体family、嵌入流/类型、ToUnicode、实际绘制字符的轮廓/字宽、可见性及阅读器检索分别核查。字体子集可能保留未用字符的空字形映射，不以全部cmap逐项对比判实际字形失败。字号、粗斜体和符号逐对象检查。可检索不等于可见；文本框同时查高度、内边距、组缩放、行距与叠放关系。

WPS缺字体提示与PDF实际字体不必一一对应。只查系统列表不能否定WPS私有字库存在；只查PDF嵌入不能证明原字体或提示全通过。仍有提示时记录其状态与已查范围；本次要求解决提示或提示影响实际格式时继续定位，不能无证据判误报，也不能仅因提示未定位就否定已核对的格式对象。

可选脚本`../scripts/check_pdf_text.py`检查页面及嵌套Form资源的嵌入/映射存在性；`--font`按本项目预期PostScript字体填写，不预设朱雀仿宋。它不验证字体流有效性、Unicode映射正确性、所有外观/字形或真实阅读器搜索；不得单独作为完整验收。

## 如何判定

| 证据 | 可以报告 | 不能据此报告 |
| --- | --- | --- |
| XML 有字体或主题声明 | 声明位置、覆盖及候选调用路径 | 该字体已安装、已绘制或已嵌入 |
| 系统 / WPS 列出字体 | 对应列表可见，内部名称仍须核对 | 实际对象一定调用它；WPS 私有字库与系统列表完全相同 |
| WPS 缺字体或受限嵌入提示 | 对应版本/副本仍有提示，触发项待定位 | 警告中的每个名字都实际用于页面；无警告即全稿通过 |
| PDF 有字体资源及嵌入流 | 该资源存在并有流；实际绘制、身份和流有效性另查 | 嵌入的一定是母版指定字体；缺字体提示已解决 |
| 抽取 / 阅读器检索成功 | 所查字符可抽取 / 在该阅读器可搜索 | 所有字符均正确、文字可见、字体未替代或分页正确 |

DOCX 字体排查按本次对象报告实际格式、必要的声明/映射证据及提示状态；只有检查 PDF 时才另报嵌入与阅读器检索。按任务保留对应未验证项，不能用其他通过项代替；未做 PDF 嵌入或检索检查不使已核验的 DOCX 格式退回未通过。以上诊断顺序是执行方法，新增 Courier / 日本语主题候选尚未完成 WPS 隔离实测；历史通过范围仍以有限记录为准。
