# 字体实际调用、嵌入与检索

保留母版实际声明及继承，先定位缺失对象。建立已知字体对照、直接声明、主题继承与未用声明等必要的隔离诊断；一次只改变待查因素。检查底层段落/链接字符样式，即使可见run有直接覆盖。诊断删除声明不等于可采用的修复。

有可用授权的同名字库时，核对内部family/PostScript名、版本、字符覆盖与技术嵌入属性，安装后重启WPS，在新副本中实际另存、确认关闭、重开和普通PDF导出。不得改字体内部名、擅换字体或关闭提醒制造通过；不默认删除缓存或替代别名。[实测范围](font-validation-2026-10-23.md)。

PDF物理尺寸及文字层直接核验，普通PDF选项不保证结果。实际字体family、嵌入流/类型、ToUnicode、实际绘制字符的轮廓/字宽、可见性及阅读器检索分别核查。字体子集可能保留未用字符的空字形映射，不以全部cmap逐项对比判实际字形失败。字号、粗斜体和符号逐对象检查。可检索不等于可见；文本框同时查高度、内边距、组缩放、行距与叠放关系。

WPS缺字体提示与PDF实际字体不必一一对应。只查系统列表不能否定WPS私有字库存在；只查PDF嵌入不能证明原字体或提示全通过。仍有提示时继续定位，不能无证据判误报。

可选脚本`../scripts/check_pdf_text.py`检查页面及嵌套Form资源的嵌入/映射存在性；`--font`按本项目预期PostScript字体填写，不预设朱雀仿宋。它不验证字体流有效性、Unicode映射正确性、所有外观/字形或真实阅读器搜索；不得单独作为完整验收。
