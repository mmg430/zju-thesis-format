# 母版实际设置与明确标注复核

本页为现行参数依据及差异登记，配合[参数表](builtin-format.md)和[继承说明](builtin-inheritance.md)使用。格式参考为浙江大学工程师学院研究生论文 DOCX 格式母版；不构成全校现行规范认证。

## 采用原则

按用途复用对应对象的实际设置，并落实明确指向待填内容的格式标注。说明文字自身的字号、边框或位置不是待填内容的格式。明确标注与示例属性有差异时，以下表的“采用方式”为准，保留差异依据；未指明的属性沿用对应对象，不自行补齐。指向不明确的说明不扩大到整段、整表或全文。

本次检查覆盖文档正文全部顶层对象及其中的说明框、表格，并核对各节、样式、编号、主题和页眉页脚引用。初次复核仅为文件静态核查；随后已用独立样稿完成[明确标注专项](annotation-format-validation.md)的 WPS 保存关闭重开，确认所查行距、Abstract 加粗、题注字号/行距及表线宽度。通过范围以下表及专项为准，不扩大到所有对象；没有导出 PDF。

## 页面、封面、标题和正文

| 对象 / 依据 | 实际属性或差异 | 采用方式 / 验证范围 |
| --- | --- | --- |
| 页面及各节 | 各节纸张 11900×16840 twip，上下边距 1440、左右 1800，页眉 851、页脚 992，装订线 0，网格 lines/312；未列镜像、奇偶页不同和页码格式/起点 | 参数保持；不以书脊附近约 3 cm 的标注重设页边距，不从手工目录推定编号规则 |
| 论文封面、中文题名页的待填题目 | 中文明确小二仿宋加粗；封面英文明确 16 pt Times New Roman 加粗；与说明占位 run 的字号不同 | 中文 18 pt 加粗，英文 16 pt 加粗；封面短题目已有[有限实测](thesis-cover-validation.md)，中文题名页及长题目未因此通过 |
| 封面姓名及导师字段 | 明确四号仿宋；说明限定部分送审阶段姓名留空 | 对应填写内容用 14 pt 仿宋，保留原字段结构；留空按实际提交阶段确认，不据说明执行外部上传或签名 |
| 章、一级节、二级节及正文 | 章标题 15 pt 加粗、22/12 pt 段距；一级节 14 pt 加粗、13/13 pt、416/240 自动行距；二级节及正文 12 pt、1.5 倍，与明确标注相符 | 按参数表复用；章标题无须另加两行占位，当前 DOCX 没有“占2行”要求 |
| 致谢、中文摘要、附录正文 | 对应示例固定 24 pt；明确标注均为小四仿宋、1.5 倍 | **采用 12 pt、1.5 倍**；缩进、强调等其余对象属性保留。所查代表段落已有专项有限通过；其他变体未验证 |
| 中文摘要字号层次 | 摘要说明段的可见文字继承 12 pt；14 pt 出现在尾部空白 run 和段落标记，不能当作正文局部字号要求 | 清理旧“正文含局部 14 pt”概括，填入内容按明确小四；不据空白 run 扩大字号 |
| Abstract 标题 | 示例 Times New Roman 15 pt 常规；明确标注小三加粗 | **采用 Times New Roman 15 pt 加粗**；保留居中及 beforeLines=100 / before=312 组合。所查标题已有专项有限通过 |
| 英文摘要内容及关键词 | 明确 Times New Roman 小四；实际正文固定 24 pt | 12 pt，行距沿用固定 24 pt；没有将中文 1.5 倍标注扩大到英文摘要 |
| 目录、图表目录 | 标签的小四仿宋标注与逐角色混合 run 分开；章级手工条目的引导符、页码实际 14 pt 常规 | 保留标签、引导符、页码的对应格式；不推断整行统一小四。自动目录是技术适配，更新后恢复及[有限实测范围](automatic-toc-validation.md)不变 |
| 标题层级 | 明确不使用四级小数标题编号，更下层使用单括号、双括号序号 | 按内容层级检查；不自动改写内容或把列表当作新增标题大纲 |

## 图表、公式和参考文献

| 对象 / 明确说明 | 实际属性或遗漏 | 采用方式 / 验证范围 |
| --- | --- | --- |
| 图题、表题 | 明确五号仿宋 / Times New Roman、单倍行距；图题在图下、表题在表上；示例题注未直接列行距 | **10.5 pt、单倍行距**，按对应上下位置排放；单倍行距是明确标注，不再写成禁止补值。所查题注字号/行距、后续多行长题注及嵌入式图片上下顺序已有[有限通过](figure-table-layout-validation.md)；所查紧密环绕浮动原型及页末行内图题定向绑定另有[有限通过](floating-caption-validation.md)，其他原型另验 |
| 题注对齐和缩进 | 常见图题居中，另有大首行缩进而未直接居中的图题；表题有 firstLine=482 | 按对应用途保留对象差异，不全篇居中或清零；不把某个示例缩进当通用值 |
| 图内文字及子图 | 明确五号仿宋 / Times New Roman；子图序号及子图名居中置于子图下方 | 可编辑文字采用 10.5 pt；像素图仍需可编辑图源确认字体，不能据外观/OCR 称已符合 |
| 流程图 | 明确框线及箭头线 0.5 pt，燕尾箭头，符号正斜体与正文一致 | 仅作用于流程图，不推广到表线；本次补录说明，WPS 未验证 |
| 曲线、照片与截图 | 数值轴向内刻度，无数值轴用箭头；轴标明物理量及单位，无量纲只标名称；照片文字用文本框外置引线；截图保持数据完整清晰 | 按对应图种检查；不擅自重画或把文本烧录进图片，不宣称所有图种已实测 |
| 表内文字 | 明确五号仿宋，英文及数字 Times New Roman；实际 10.5 pt、1.5 倍 | 保留对应字体与段落、单元格用途；没有全表表头加粗要求 |
| 表线 | 明确通常为三线表、表线 0.75 pt；所查示例表/单元格边线 sz=4，即 0.5 pt | **通常采用三线表，适用表线 0.75 pt（sz=6）**；检查表级及单元格覆盖，不强制所有特殊表去内部线。所查单元格及后续普通跨页表格整体线宽已有[有限通过](figure-table-layout-validation.md)，旧示例属性不再充当默认值 |
| 公式与符号 | 需引用或重要公式按章编号，附录按字母章编号；单位/函数等正体，物理量/变量等斜体，矢量/张量/矩阵黑斜体，下标按含义区分 | 按语义核对，不全局替换未知字符；计量单位与数值间留空隙，角度单位除外；未以说明推定公式字库。Cambria Math 实际公式及这些细项 WPS 未验证 |
| 正文引用与书目顺序 | 明确正文引用以上标标注，文末按首次引用顺序连续中括号编号 | 检查引用与条目对应；不替换为样例文献，不凭排版推定来源真实性 |
| 参考文献字体、行距与缩进 | 明确小四仿宋 / Times New Roman、1.5 倍；实际列表含多层组合缩进 | 字体 12 pt、1.5 倍，保留组合缩进；[已测单/双位数编号范围](bibliography-indent-validation.md)仍有效，不扩大为全部题录形式通过 |
| 书目题录写法 | 母版说明区分期刊、专著、析出、学位论文、专利、标准、报纸、报告、电子文献；标点按中英文区分；对作者姓名完整性及多人署名另有说明 | 按已选母版和真实题录逐项核对，见下文；这些说明的来源已查，未作 WPS 排版实测或现行引用标准认证 |

### 书目检查范围

逐类型检查作者/责任者、题名、文献类型及相应出版来源：期刊的年卷期页码，专著的版本/出版地/出版社/年份，析出的所在文集及编者，学位论文的地点/授予单位/年份，专利的国家/编号/日期，标准的编号，报纸的日期/版次，报告的发布机构，以及电子资源的载体/来源/日期。缺失信息如实标出，不补造。

母版说明采用中文标点全角、英文标点半角；要求英文姓名不随意缩写，并区分中英文姓名顺序与多人署名。中文多作者按所述前三位加“等”处理；英文按其姓名次序和连接方式核对，不据此猜全名。若任务采用不同的明确题录标准，单列该来源及差异，不能把本母版说明冒充所有现行标准。模板中列出的文献类型/载体代码用于对应条目，不为未知文献强配类型。

## 验证记录如何使用

- 参数表写当前采用设置；继承表记录原对象属性，包括与标注不一致的示例属性；本页解释差异和采用范围。
- 致谢/中文摘要/附录代表正文的 1.5 倍、Abstract 标题加粗、所查题注单倍及五号、单元格 0.75 pt 表线，已有[独立样稿 WPS 保存重开有限通过](annotation-format-validation.md)。新增证据只覆盖本次对象，不用历史字体实验代替，也不扩大到全部变体。
- 目录修正、组合缩进、静态页眉、编号适配及封面等旧实验只在各专项已记录范围内有效；没有被本次明确标注专项重新执行。
- 不增加源文件未明确的页码起点、奇数页起章、空白页、段距、封面图像位置或统一字体；保留目标版本及对象的待查项。验收仍以 WPS 中 DOCX 实际格式为准，XML 辅助排查，PDF 按需。

后续[重复表头与显式续表题](table-continuation-validation.md)已在独立样稿保存关闭重开后有限通过；两项为按需技术适配，母版未设为默认，自动续表题及复杂变体仍未验证。

后续[表头专项](table-continuation-validation.md)已补充所查两行连续表头及横纵合并三行表头的 WPS 保存关闭重开有限结果；保持对应表内段落格式，不扩大至其他复杂合并或自动续题。

[自动续题内容变化对照](table-continuation-validation.md)记录：所查分页与重复表头随增删文字保持，PAGE/PAGEREF 条件候选未生成续表标识，不采用；当前副本改用显式续题后重开通过，不扩大为自动续题通过。

## 字体、字号与颜色补核

2026-10-24 已只读核对各对象、主题/样式、编号和页眉页脚，见[字体字号颜色核对表](font-size-color-audit.md)。补入前页字段、声明、宋体节标题例外、显式黑色/主题链接色/说明深灰与缺省差异；不将说明字号或颜色复制为填写要求，也不把原型差异改成全篇统一。初次结果为属性核对；随后独立样稿的姓名字段、宋体节标题及链接蓝色显示取得有限 WPS 保存关闭重开证据，其他对象与精确颜色/字库身份未随之通过，见专项末节。以本表和专项保留对象差异。


前后置页的分对象排布、字体及颜色已集中补入[前页格式表](front-matter-format.md)。声明与授权分别保留 1.5 倍/固定 28 pt 的正文设置，签名字段另按原型；题名页不套正文样式。新增清单为源属性核对，不扩展既有 WPS 通过范围。
