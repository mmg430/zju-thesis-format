# 重复表头与显式续表题实测

## 依据与验证范围

2026-10-23，macOS、WPS Office 教育版 12.1.25867；独立 DOCX 完成另存、关闭、从磁盘重开，没有导出 PDF。验收以重开后的 WPS 实际显示与属性面板为准，XML 只辅助检查行序和标记是否保留。

母版所查普通表格没有重复表头标记，也没有续表题示例或对应明文要求。本轮按跨页处理需要增加这些功能，属于**技术适配**，不追认为母版默认。表内字体、字号、段落、列宽和缩进复用对应对象；表线按母版明确标注采用 0.75 pt，题注按五号、单倍及原居中/缩进处理，不自行加粗表头。

| 项目 | WPS 重开后的证据 | 结论 |
| :--- | :--- | :--- |
| 连续表格重复表头 | 各所查续页顶部重现首行，行属性“标题行重复”保持启用；后续行依次接续，包含允许行内跨页时的剩余文字 | 所查普通两列表格有限通过 |
| 显式分段续表题 | 后段前放置同一表号、原题名加“（续）”的题注，复制原表头与列宽；题注在表格上方，与首行相邻，没有重叠，分段前后行序连续，末行和后续正文完整 | 所查显式续表方法有限通过 |
| 续表题外观 | 字体面板为仿宋 / Times New Roman、五号常规；段落面板为单倍，保留对应原缩进与居中 | 对应外观有限通过；不新增实际字库身份验证 |

## 可复用处理步骤

1. 需要重复表头时，只选中表格顶部连续的表头行，启用“标题行重复”（表格菜单或表格属性的行选项）。保留原表头字体、粗细、行高和列宽；不要将普通数据行误选为标题。单纯重复表头不会自动生成表外续表题。
2. 如需本轮已测的续表题处理，在实际合适的行边界显式分为前后段；后段复制同一表格的表头、列网格及对应单元格格式，数据行继续原顺序，不重新编号或新增一张表的编号。不得切开合并关系或丢掉跨页行残余文字。
3. 后段前复制母版对应表题段落，沿用原表号和题名，并加续表标识。本轮用“（续）”区分续段，仅是此次技术适配的标识，不声称母版规定该字样；有另行明确要求时按选定要求处理。
4. 续表题设置“与下段同页”，使其与后段表格起始处相邻；本轮后段从下一页开始；保留题注字体、字号、单倍行距、居中及缩进。这里的分页和绑定属于局部适配，不是母版默认；不添加固定空行，不照搬样稿的分表行号或页码。
5. 保存关闭重开，逐处核对表头、续题与表格的位置、列宽、分段行序、行内跨页残余文字、末行及后续正文。发现实际错位或分离，再只修正对应段落/表格属性，复验通过后报告结果。

## 剩余限制

显式续表题和分段位置不会随内容变化自动重新规划。正文或表格改动导致重新分页时，须重新检查并移动分界及续题；本轮不证明“自动续表题”或任意编辑后都能自动保持。

多行/合并表头、复杂合并或嵌套表、跨段公式与编号、超高单元格、禁止行内跨页及其他 WPS/操作系统仍未在本轮验证。原表允许行内跨页时，正文残余行出现在重复表头下方不直接判为错误，应查明是否有遗漏或被遮挡，再按选定要求决定是否另行调整。完整母版、论文、打印或 PDF 不新增验证。公开记录不包含样稿、源母版、个人路径、固定页数或断点行号。
