# 重复表头与续表题实测

## 依据与验证范围

2026-10-23，macOS、WPS Office 教育版 12.1.25867；独立 DOCX 完成另存、关闭、从磁盘重开，没有导出 PDF。验收以重开后的 WPS 实际显示与属性面板为准，XML 只辅助检查行序和标记是否保留。

母版所查普通表格没有重复表头标记，也没有续表题示例或对应明文要求。本轮按跨页处理需要增加这些功能，属于**技术适配**，不追认为母版默认。表内字体、字号、段落、列宽和缩进复用对应对象；表线按母版明确标注采用 0.75 pt，题注按五号、单倍及原居中/缩进处理，不自行加粗表头。

| 项目 | WPS 重开后的证据 | 结论 |
| :--- | :--- | :--- |
| 连续表格重复表头 | 各所查续页顶部重现首行，行属性“标题行重复”保持启用；后续行依次接续，包含允许行内跨页时的剩余文字 | 所查普通两列表格有限通过 |
| 显式分段续表题 | 后段前放置同一表号、原题名加“（续）”的题注，复制原表头与列宽；题注在表格上方，与首行相邻，没有重叠，分段前后行序连续，末行和后续正文完整 | 所查显式续表方法有限通过 |
| 续表题外观 | 字体面板为仿宋 / Times New Roman、五号常规；段落面板为单倍，保留对应原缩进与居中 | 对应外观有限通过；不新增实际字库身份验证 |

## 可复用处理步骤

1. 需要重复表头时，只选中表格顶部连续的表头行，启用“标题行重复”（表格菜单或表格属性的行选项）。保留原表头字体、粗细、行高和列宽；不要将普通数据行误选为标题。单纯重复表头不会自动生成表外续表题。
2. 如需本轮已测的续表题处理，在实际合适的行边界显式分为前后段；后段复制同一表格的表头、列网格及对应单元格格式，数据行继续原顺序，不重新编号或新增一张表的编号。不得切开合并关系或丢掉跨页行残余文字。
3. 后段前复制母版对应表题段落，沿用原表号和题名，并加续表标识。本轮用“（续）”区分续段，仅是此次技术适配的标识，不声称母版规定该字样；有另行明确要求时按选定要求处理。
4. 续表题设置“与下段同页”，使其与后段表格起始处相邻；本轮后段从下一页开始；保留题注字体、字号、单倍行距、居中及缩进。这里的分页和绑定属于局部适配，不是母版默认；不添加固定空行，不照搬样稿的分表行号或页码。
5. 保存关闭重开，逐处核对表头、续题与表格的位置、列宽、分段行序、行内跨页残余文字、末行及后续正文。发现实际错位或分离，再只修正对应段落/表格属性，复验通过后报告结果。

## 剩余限制

显式续表题和分段位置不会随内容变化自动重新规划。正文或表格改动导致重新分页时，须重新检查并移动分界及续题；本轮不证明“自动续表题”或任意编辑后都能自动保持。

其他复杂合并或嵌套表、跨段公式与编号、超高单元格、禁止行内跨页及其他 WPS/操作系统仍未在本轮验证。原表允许行内跨页时，正文残余行出现在重复表头下方不直接判为错误，应查明是否有遗漏或被遮挡，再按选定要求决定是否另行调整。完整母版、论文、打印或 PDF 不新增验证。公开记录不包含样稿、源母版、个人路径、固定页数或断点行号。

## 多行及横纵合并表头补充实测

同日、同版 WPS 另用独立 DOCX 完成保存、关闭、磁盘重开；不导出 PDF。母版普通表未提供此类表头结构，本轮保留对应表内文字、列宽及段落格式，将新增表头层级和合并关系明确作为测试适配，不新增通用字体或位置要求。

| 所查结构 | 重开后的结果 | 范围 |
| :--- | :--- | :--- |
| 两行连续表头，首行含自然换行的长文字 | 两行及完整文字在所查续页重复，列边界一致，后续数据和末行正常 | 此两行原型有限通过 |
| 三行表头：顶部横向跨两列；下方左列纵向合并两行、右列分为上下两层 | 各所查续页保持整组三行及横纵合并外观，无可见拆散、重叠或遮挡；数据连续、末行与后续正文完整 | 此组合原型有限通过，不推广至任意复杂合并 |

重开后，所查合并表头各行的行属性均显示重复启用，紧接的首条数据行未启用；字体面板保留仿宋 / Times New Roman、五号常规，多行表头段落仍为对应原型的 1.5 倍。不要把题注单倍行距套用到表内。本轮未发现需要定向修正的实际格式偏差。

复用时，把**从表格首行开始的整组连续表头行**一起标记为重复，包含纵向合并涉及的全部表头行；不要只处理可见第一层，也不要把数据行或跨入数据区的纵向合并机械纳入。保留原合并关系、列网格、字体、粗细和段落，实际查看每处跨页；本轮不需要拆开合并、改为图片、固定行高或禁止全部数据行跨页。

这两组结果补充前述“多行/合并表头”未覆盖范围。更多列和层级、合并跨越表头与数据边界、嵌套表、超高表头及任意重排仍未验证；自动续表题尚无通过方案；所测候选结果见下节。样稿页数、表头数量与数据行号不成为通用规则。源母版和论文未覆盖，字体实际字库身份、完整文档、其他环境及 PDF 不新增验证。

## 自动续表题候选与内容变化对照

同日、同版 WPS 用独立样稿检查“题名放入重复行，比较 PAGE 与首处书签 PAGEREF，续页由 IF 增加续表标识”的候选。这个题注入表结构只用于实验，未作为母版排版方法采用，也不据此声称其外观完整符合母版。

对照包含：基线、扩展表格前文字、再删除扩展文字。各版更新域后均另存、关闭、从磁盘重开，检查首续页及数据；本轮无 PDF。

| 检查 | 实际结果 | 状态 |
| :--- | :--- | :--- |
| 内容改变后的分页与重复表头 | 增文后实际跨页分界移动，重复题名和表头随分页移动，数据续接正常；删回后分界恢复 | 所查重复与分页有限通过，不等于自动续题通过 |
| 条件续表标识 | 基线、增文及删回后，续页均未出现应有的续表标识，保存重开未修复 | **此候选未通过，不采用** |
| 可见域诊断 | PAGE 从预置值更新为首处页码，简单真假 IF 从预置假值变为真，证明所查域已更新；但 PAGE 在续页重复实例中仍显示首处页码 | 支持本轮条件无法区分首续页的诊断，不推广为所有域或版本的结论 |
| 定向修正当前副本 | 移除候选题注行和条件域，复用原表外题注并显式分段：首段普通题名，后段同号题名加续表标识；重开后各段题注/表头相邻、数据和末行完整，所查题注仍为五号常规仿宋 / Times New Roman | 当前版本的显式修正有限通过，**不算自动续题解决** |

来源参考：[WPS 学堂的重复表头说明](https://www.wps.cn/learning/room/d/323544)说明顶端标题行的重复功能；它不构成本轮条件域续题或当前 Mac 版本自动续表题的通过依据。公开资料用于寻找候选，实际验收仍以本轮 WPS 观察为准。

后续处理：已有显式续题按前述步骤使用；内容变化后重新校准分段及题注。不要把“重复同一题名”、更新域调用成功、单页缓存结果或静态续题修正冒称自动续表题。当前尚无在此环境中通过内容变化对照的自动续题方案；其他候选仍待验证，不据本轮失败断言 WPS 所有版本都无法实现。母版未提供自动续题要求或原型，不以此候选改写内置字体、题注位置或表格默认结构。
