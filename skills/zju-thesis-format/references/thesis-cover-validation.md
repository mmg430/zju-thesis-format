# 论文封面：母版复用与有限 WPS 实测

## 已更正的对象识别

格式参考为浙江大学工程师学院研究生论文 DOCX 格式母版。其论文封面示例**确有独立的校名字样和圆形校徽**，分别锚定在含说明文本框的段落中。此前仅检查规范说明首页组合标识、遗漏这两个图像对象，是识别遗漏，不是母版缺少图源或位置依据。不能因此要求使用者重新设计封面。

规范说明首页的组合标识与论文封面这两个对象分开，前者见[旧对象实测及更正](cover-emblem-validation.md)。复用封面时读取图片关系与所在段落全部对象，不把含说明文字的整段删除；移除说明框时保留同段校名/校徽图像和锚点。

## 按母版采用的设置

| 对象 | 来源依据与处理 |
| --- | --- |
| 校名字样 | 原 PNG 523 × 167 像素；显示 2171700 × 693420 EMU，约 6.033 × 1.926 cm；浮动锚点，上下型环绕 |
| 圆形校徽 | 原 PNG 197 × 186 像素；显示 819150 × 775335 EMU，约 2.275 × 2.154 cm；浮动锚点，上下型环绕 |
| 图片位置 | 保留母版原锚定段落、相对基准、偏移及前后段落，不把首页组合图的嵌入式设置套给这两个对象，不凭截图另设坐标 |
| 页及字段 | 保留页面边距、空段、分类/密级/学号栏、题目栏、人员信息与日期栏的对应段落、逐 run 字体和下划线，不用正文常用格式覆盖整张封面 |
| 填入中文题目 | 母版明文标注“小二号仿宋体加黑”，填入内容采用仿宋 18 磅加粗 |
| 填入英文题目 | 母版明文标注“16pt Time New Roman，Bold”，填入内容采用原声明对应的 Times New Roman 16 磅加粗 |

以上图片数值是该母版对象的来源参数，不叠加给其他模板。题目字号属于母版对待填内容的明确说明；说明文字自身的显示字号与待填题目分开，不把它误当题目的格式，也不将该填写说明推广到其他对象。其余既有字体、段内差异和页面设置按实际对象复用，不自行补造。

## 实施与本次结果

以独立样稿复用母版论文封面段落、原图及浮动锚点，定向移除说明文本框和箭头，保留同段图像。题目使用短中性文字，按上述明确填写说明处理；其他字段保留母版占位结构，未填写真实个人信息。初次样稿仅沿用说明占位 run 的字号，后按明确标注修正题目，旧版本不作为当前交付。

在 Mac WPS 教育版 12.1.25867 中实际另存 DOCX、关闭至首页、从磁盘重开后：

- 所查封面为单页，校名字样、学位论文类别、圆形校徽、题目、人员信息和日期栏按母版原型排布，未见图片遮挡或裁切。
- 短中英文题目按对应字号及加粗显示，修正后保存重开保持；标签和其他字段没有随题目统一改号。
- 两张原图资源保存后未重新编码，浮动锚点和上下型环绕保留。类型和尺寸由属性辅助核对，WPS 实际显示为验收重点；未单独取得环绕下拉菜单的选中项读数，不声称其他环绕交互通过。

不导出 PDF；未覆盖母版或论文稿。公开只记录参数、方法及有限结果，不附带母版、封面 DOCX、校名/校徽图像或截图。

## 仍需按目标核对

WPS 仍显示缺字体提示，本轮保留母版原声明，没有完成所有前页字体的实际调用定位；相关问题见[前页字体保留项](front-numbering-validation.md)。字体声明复用与实际映射通过分别记录。真实长题名、人员字段长度变化、不同提交场景、完整前置材料、其他 WPS/系统及真实打印仍未覆盖；不将单页样稿推广为所有题目都能单页。此次明确填写说明的处理不授权改写其他母版参数或正文内容。
