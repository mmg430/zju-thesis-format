# 参数提取与验证状态

本表用于**自定义模板模式**：用户提供自己的 DOCX 模板时，按下表提取其实际属性，建立新的排版配置，不叠加内置数值。需要直接使用仓库已有排版时，读取[内置方案](builtin-format.md)，无需提供源母版。来源及适用要求见[来源边界](format-rules.md)。

| 对象 | 从母版读取并保留 | 状态边界 |
| --- | --- | --- |
| 页面及各节 | pgSz、pgMar、装订线、页眉页脚距边、网格、节起始及页码设置，逐节核对 | XML读取与WPS往返分别记录；不把名义A4覆盖原twip |
| 文档设置和主题 | mirrorMargins、evenAndOddHeaders、字体主题及脚本映射等 | 缺省不等于显式关闭；不自行开启双面或全篇去网格 |
| 各级标题和正文 | basedOn继承与link关联（分别记录）、直接覆盖、对齐、行距/段距、缩进、keepNext/keepLines、字体及字重 | 按母版对应对象复用，不把某一级的数值推广全篇 |
| 图题、表题和表格 | 逐run混合格式、表格样式、tblPr/tblGrid/trPr/tcPr及单元格段落、边框与编号 | 不统一题注单倍、表头加粗或重建三线表；跨页按实际对象重验 |
| 目录和书目 | 手工/域结构、标题大纲、TOC 层级映射、制表位、缩进、编号及逐角色混合格式 | 不自造缩进；新增自动目录标为适配，更新后回查域载体及结果；目录页码、DOCX 点击和 PDF 跳转分别验证；本次 Mac WPS 的 Command 单击抽样方法不推广为其他环境默认，见[内置方案有限实验](automatic-toc-validation.md)，不叠加其数值 |
| 页眉页脚 | 节引用及继承、章名/域、对齐、横线及PAGE域 | 章名按目标内容更新；不复制样例固定页码或强加空白页 |
| 字体 | ascii/hAnsi/eastAsia/cs、主题/字符样式和逐run覆盖；底层样式即使被直接格式覆盖仍须保留 | 输出family、嵌入、字形身份和缺字体提示分开核查；不删Cambria等声明消除提示 |
| 图内文字 | 可编辑文本框按原属性；像素图需可编辑图源确认字体 | 外观或OCR不能证明栅格图字体身份 |

证据分类：**实际属性**＝已读取的母版XML；**明文说明**＝文档文字，不能自动覆盖实际属性；**项目适配**＝获准对象上的内容/显示修复；**WPS已验证**＝指定应用版本及同版本DOCX/PDF实际往返；**未验证/待核实**须保留范围。

[最新有限实测](font-validation-2026-10-23.md)支持按授权补齐同名原字库并保留声明的技术方法，不分发字体。内置参数并非适用于所有模板的统一数值。字体安装后的字宽可能影响换行/分页，新稿必须重验。自定义模板改变时重新提取。

段落标记 `pPr/rPr`、文字 run、嵌套文本框及域结果分别提取；不能把段落标记或说明框字号套给整段正文。多层缩进、主题及开关属性保留来源，不简单合并成一个未经输出验证的值。只读检查不改变文档；修改和验证层级见[验收方法](full-manuscript-validation.md)。
